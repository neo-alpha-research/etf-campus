직전 지시서에서 다음과 같이 썼습니다.

> `cba7821` 로 KOSPI 와 KOSDAQ 만 보내도록 하신 판단이 옳습니다. 되돌리지 마십시오.

**틀렸습니다.** 데이터베이스 제약만 보고 **STEP 1 화면이 무엇을 필요로 하는지 확인하지 않았습니다.**

현재 STEP 1 거시 지표가 4개 열 중 국내 증시만 채워지고 **미국 증시, 채권 및 금리, 원자재 세 열이 비어 있습니다.** 이전에는 열당 3개씩 총 12개가 표시되었습니다.

## 2. 확인된 연결 고리

발신 측에서 코드를 읽어 확인한 경로입니다.

```
publish_market_source_snapshot.py
  → cba7821 이 KOSPI, KOSDAQ 외 전부 제외 (continue)
  → CODE_MAP (^TNX→DGS10, ^VIX→VIXCLS) 도 함께 제거됨

market_source_index_daily          CHECK (index_code IN ('KOSPI','KOSDAQ'))
source-materializer.ts L128        if (indices.length !== 2) throw "source_indices_incomplete"
source-materializer.ts L165        → market_index_daily 로 복사
market_index_daily (0014)          CHECK IN ('KOSPI','KOSDAQ','TNX','DGS10','DGS2','T10Y2Y','VIX','CLF')

functions/api/briefings/latest.js L94   marketIndices: metrics.market_indices
components/market-briefing/market-briefing.tsx L719~763   4개 열로 렌더링
```

**제약이 세 곳에 걸려 있습니다.** 허브 테이블 CHECK, 머티리얼라이저의 `!== 2` 판정, 그리고 그 아래 `market_index_daily` 는 8개 코드를 허용합니다.

## 3. 먼저 답해야 할 질문 하나

**과거에는 어떻게 7개가 들어갔습니까?**

2026-08-21 브리핑에는 `CLF`, `DGS10`, `DGS2`, `KOSDAQ`, `KOSPI`, `T10Y2Y`, `VIX` 7개가 있었습니다. 2026-08-24 부터 2개로 줄었습니다.

**허브 테이블 CHECK 가 2개만 허용하는데 7개가 통과한 경로가 있었다는 뜻입니다.**

### 3-1. 확인할 것

**`market_briefings.metrics_json` 의 `market_indices` 를 무엇이 만드는지** 코드에서 찾으십시오. 머티리얼라이저인지 다른 곳인지입니다.

**2026-08-21 행의 `metrics_json` 에서 `market_indices` 를 조회해** 실제로 몇 개가 들어 있는지 확인하십시오. 이것은 `SELECT` 이므로 실행해도 됩니다.

**프로덕션 D1 의 `market_source_index_daily` 테이블 정의를 실제로 조회하십시오.**

```sql
SELECT sql FROM sqlite_master WHERE name='market_source_index_daily';
```

**마이그레이션 파일과 실제 테이블이 다를 수 있습니다.** 8월 21일에 7개가 들어갔다면 실제 제약이 다를 가능성이 있습니다.

**`market_index_daily` 도 같은 방식으로 조회하십시오.**

### 3-2. 이 답이 수정 방향을 결정합니다

**허브 테이블이 실제로 8개를 허용하면** `cba7821` 의 필터만 되돌리고 `CODE_MAP` 을 복원하면 됩니다. 머티리얼라이저의 `!== 2` 판정만 함께 고치면 끝입니다.

**허브 테이블이 정말 2개만 허용하면** 마이그레이션이 필요하고, 그 경우 허브를 늘릴지 아니면 국내 지수와 글로벌 지수를 분리된 경로로 다룰지 판단이 필요합니다.

**둘 중 어느 쪽인지 확인한 뒤 보고하십시오. 추정으로 진행하지 마십시오.**

## 4. 복구 목표

**이전 화면 구성으로 되돌리는 것이 목표입니다.**

```
국내 증시    코스피, 코스닥, 원/달러
미국 증시    S&P 500, 나스닥, 니케이 225
채권 및 금리  미 국채 10년물, VIX, 그 외
원자재       WTI 원유, 금 선물, 은 선물
```

**정확한 구성은 `market-briefing.tsx` 의 렌더링 코드를 읽어 확인하십시오.** 어느 코드가 어느 열에 들어가는지 매핑이 컴포넌트에 있습니다.

**그 매핑에 필요한 코드 목록이 곧 허브를 통과해야 하는 목록입니다.**

**티커 표시에서 제외한 원자재 3종은 STEP 1 에는 나와야 합니다.** 앞서 티커에서만 제외했고 브리핑 본문에서는 쓰기로 했습니다.

## 5. 수정 시 지킬 것

**`CODE_MAP` 을 복원할 때 벤더 심볼과 내부 코드를 명확히 구분하십시오.**

```
^TNX  →  DGS10 또는 TNX
^VIX  →  VIXCLS 또는 VIX
CL=F  →  CLF
```

**`market_index_daily` 의 CHECK 목록에 있는 코드로 맞추십시오.** 목록에 없는 코드를 보내면 적재가 실패합니다.

**머티리얼라이저의 `indices.length !== 2` 를 고칠 때 검증을 없애지 마십시오.** KOSPI 와 KOSDAQ 이 반드시 포함되어야 한다는 조건은 유지하고, 개수 상한만 풀거나 기대 개수를 맞추십시오.

**검증을 통과시키려고 데이터를 줄이지 마십시오.** 이번 사고가 정확히 그 결과입니다.
