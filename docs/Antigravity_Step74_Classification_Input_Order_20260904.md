## 0. 이번 라운드는 지시대로 정확히 수행되었습니다

**데이터로 전수 확인했습니다. 한 건도 어긋나지 않았습니다.**

```
pension_source     법령조건직접판정 64 / 규칙기반추정 1,103
pension_verified   Y 5 / N 1,162
pension_confidence 높음 1,075 / 보통 92
커버드콜 62        높음 3 (전부 verified=Y) / 보통 59
법령조건직접판정 64  커버드콜 포함 0건
```

**커버드콜이 영역 B 에서 완전히 빠졌고, 판정 순서에서 영역 D 를 먼저 평가하도록 배치한 것도 정확합니다.**

**2축 분리도 의도대로 작동합니다.** 외부 대조로 확인한 5종목이 판정 근거와 무관하게 신뢰도 높음을 유지하면서 `pension_verified = Y` 로 남았습니다. 앞으로 운용사 목록을 대조할 때 실적이 누적됩니다.

## 1. 발신 측 계산이 틀렸고 그것을 잡아내셨습니다

**Step73 에서 "보통 90, 커버드콜 57" 이라고 썼습니다. 틀렸습니다.**

**표본 5종목이 전부 커버드콜이라고 가정하고 `62 - 5 = 57` 로 계산했습니다.** 실제로는 커버드콜이 3종목이고 나머지 2종목은 일반 합성입니다.

```
0000D0  TIGER 엔비디아미국채커버드콜밸런스(합성)   커버드콜
289480  TIGER 200커버드콜                    커버드콜
441680  TIGER 미국나스닥100커버드콜(합성)         커버드콜
0005C0  RISE 미국S&P500엔화노출(합성 H)         일반 합성
181480  ACE 미국부동산리츠(합성 H)              일반 합성
```

**`62 - 3 = 59`, `33 + 59 = 92` 가 맞습니다.**

**지시서 숫자에 맞추려고 데이터를 조정하지 않고, 실측 결과와 차이가 나는 이유를 설명하신 것이 옳습니다.**

**오늘 여러 차례 지적한 문제의 정반대 행동입니다. 이 방식을 유지하십시오. 발신 측 지시에 틀린 숫자가 있으면 앞으로도 그렇게 처리하십시오.**

**폐기 파일 8건 내역 보고도 요청한 형식대로였습니다.**

## 3. 그런데 더 근본적인 문제를 발견했습니다

**발신 측에서 분류 원천 파일을 직접 확인했습니다. 규제 판정 엔진의 입력이 어긋나 있습니다.**

### 3-1. 판정 근거가 기본값인 종목이 789건입니다

`data/classification/etf_classification_review_draft.csv` 의 `asset_basis` 분포입니다.

```
주식 기본값·기존 분류 참고        789    전체의 67.6%
채권 키워드                     136
혼합·자산배분 키워드              81
원자재 밸류체인·생산기업 주식 키워드   49
금리·파킹 키워드                 44
원자재 현물·선물 직접 노출 키워드    24
리츠·인프라 키워드                12
통화 선물·지수 키워드              12
```

**"기본값" 은 어느 키워드에도 걸리지 않아 주식으로 떨어뜨렸다는 뜻입니다. 판정된 것이 아닙니다.**

**보고서에서 지적하신 탄소배출권 두 종목이 정확히 이 경로였습니다.**

```
400590  SOL 글로벌탄소배출권선물ICE(합성)     final_asset_class 주식   근거: 주식 기본값
401590  HANARO 글로벌탄소배출권선물ICE(합성)   final_asset_class 주식   근거: 주식 기본값
```

**두 종목만의 문제가 아니라 789건이 같은 상태입니다.**

### 3-2. 리뷰 파일과 마스터가 131건 어긋납니다

**`final_asset_class` 와 마스터의 `asset_class` 를 전수 대조했습니다.**

```
0000D0  TIGER 엔비디아미국채커버드콜밸런스(합성)   리뷰 혼합자산  →  마스터 채권
0013R0  RISE 테슬라미국채타겟커버드콜혼합(합성)    리뷰 혼합자산  →  마스터 채권
0049K0  ACE 미국배당퀄리티채권혼합50           리뷰 혼합자산  →  마스터 채권
0052S0  1Q 미국S&P500미국채혼합50액티브        리뷰 혼합자산  →  마스터 채권
0036Z0  RISE 미국천연가스밸류체인               리뷰 주식     →  마스터 원자재
219390  RISE 미국S&P원유생산기업(합성 H)        리뷰 주식     →  마스터 원자재
   외 125건
```

**`219390` 은 리뷰 파일이 이미 주식으로 판정해 두었습니다. 마스터가 따라가지 않은 것입니다. 분류가 없었던 것이 아니라 전파가 안 된 것입니다.**

### 3-3. 이것이 규제 판정으로 직접 전파됩니다

**`0000D0 TIGER 엔비디아미국채커버드콜밸런스(합성)` 을 보십시오.**

```
마스터 asset_class   채권       →  100% 안전자산으로 분류됨
리뷰 final_asset_class 혼합자산
```

**혼합자산이면 주식 비중 50퍼센트 이하 요건을 확인해야 합니다. 채권으로 분류되어 그 검증을 건너뛰었습니다.**

**엔비디아 주식이 들어간 커버드콜 상품이 퇴직연금 안전자산 30퍼센트 의무를 채우는 데 쓰일 수 있는 상태입니다.**

**오늘 판정 엔진을 정교하게 다듬는 동안, 그 엔진이 읽는 입력은 검증하지 않았습니다.**

### 3-4. 지시

**일괄 덮어쓰지 마십시오. 어느 쪽이 정답인지 종목마다 다릅니다.**

**먼저 전파 경로를 확인하십시오.** 리뷰 파일의 `final_asset_class` 가 마스터의 `asset_class` 로 반영되는 스크립트가 있는지, 있다면 왜 131건이 남았는지입니다. **없으면 전파가 수동이었다는 뜻이므로 그 사실을 보고하십시오.**

**131건을 유형별로 분류해 보고하십시오.**

```
리뷰 혼합자산 → 마스터 채권      안전자산 오판정 위험. 최우선
리뷰 주식    → 마스터 원자재     노출 분류 오류
그 외
```

**첫 유형이 몇 건인지, 그중 현재 100퍼센트 안전자산으로 분류된 종목이 몇 건인지 세어 보고하십시오.**

**789건 기본값 중 퇴직연금 안전자산으로 분류된 종목이 있는지 확인하십시오.** 있으면 그것이 두 번째 우선순위입니다.

**이번 라운드는 조사와 보고까지입니다. 분류를 고치지 마십시오.**
