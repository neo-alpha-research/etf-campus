## 1. 발신 측 판단이 틀렸습니다

**운영자께서 다음을 물으셨습니다.**

> 목표가 50퍼센트인데 보유하다 주가가 올라서 50퍼센트를 넘어 버리면 안전자산이 아닌 위험자산으로 보아야 한다는 근거나 규정이 있나요

**근거가 없습니다. 확인 결과 발신 측 설계가 틀렸습니다.**

### 1-1. 펀드 분류는 약관 기준입니다

**자본시장법상 집합투자기구 분류는 정관과 약관에 명시된 투자 비중으로 결정됩니다.**

```
채권혼합형   약관상 주식에 50퍼센트 미만 투자
```

**시장 변동으로 실제 편입비율이 일시적으로 벗어나는 것은 분류를 바꾸지 않습니다.**

**따라서 목표 50퍼센트 상품이 주가 상승으로 50.09퍼센트가 되었다고 위험자산이 되지 않습니다.**

### 1-2. 퇴직연금 안전자산 판정 기준은 미확인입니다

**퇴직연금감독규정의 안전자산 판정이 약관 기준인지 실제 편입 기준인지는 확인되지 않았습니다.** 2차 자료가 엇갈리고 조문 인용이 없습니다.

**[미확인] 으로 남깁니다. 추정으로 채우지 마십시오.**

### 1-3. 그리고 판정 주체가 우리가 아닙니다

**퇴직연금 계좌의 안전자산 위험자산 판정은 증권사 전산이 수행합니다. 증권사는 상품별 분류를 사전에 확정해 두고 씁니다. 매일 실측 비중으로 재판정하지 않습니다.**

**우리가 실측으로 매일 재판정하면 증권사 전산과 다른 답을 내놓게 됩니다.**

**사용자는 우리 화면에서 위험자산으로 보고 증권사에서는 안전자산으로 매수하게 됩니다. 오분류를 고치는 것이 아니라 새로 만드는 것입니다.**

## 2. 실측의 올바른 용도

```
잘못된 설계   measured_equity_pct <= 50           →  안전자산으로 판정
올바른 설계   설계 비중과 실측이 크게 어긋나면        →  검토 대상으로 보고
```

**실측은 판정 기준이 아니라 이상 탐지 도구입니다.**

**`251600` 이 50.09퍼센트인 것은 문제가 아닙니다.** 설계가 50 대 50 이고 주가가 조금 올랐을 뿐입니다.

**반면 `183710` 과 `341850` 은 실측이 문제가 아니었습니다.**

```
183710  RISE 주식혼합              이름부터 주식혼합. KOSPI200 70% 설계
341850  TIGER 리츠부동산인프라채권    리츠 70% 설계
```

**둘 다 애초에 약관상 위험자산 상품이었고 마스터가 채권으로 잘못 분류하고 있었습니다.**

**실측은 그 사실을 발견하는 도구였을 뿐 판정 근거가 아니었습니다.**

**수정 사유를 다시 쓰면 "실측 70퍼센트라서" 가 아니라 "설계 자체가 주식 70퍼센트 상품이라서" 입니다.**

## 3. 두 영역을 구분하십시오

**실측이 강한 증거가 되는 영역과 그렇지 않은 영역이 다릅니다.**

### 3-1. `asset_class` 검증에는 실측이 강력합니다

**`asset_class` 는 규제 판정이 아니라 상품 성격 분류입니다. 약관 기준 논쟁과 무관합니다.**

**구성종목이 압도적으로 채권이면 그 상품은 채권형입니다. 탄소배출권 선물만 담고 있으면 주식형이 아닙니다.**

```
400590  SOL 글로벌탄소배출권선물ICE(합성)   asset_class 주식-해외   명백한 오류
219390  RISE 미국S&P원유생산기업(합성 H)    asset_class 원자재      실제는 주식
```

**789건 기본값과 131건 불일치는 이 영역입니다. 실측으로 판정하십시오.**

### 3-2. 안전자산 판정에는 실측을 쓰지 마십시오

**53건 이름 규칙 영역입니다. 약관 비중이 기준이므로 실측으로 뒤집으면 안 됩니다.**

**대신 괴리 탐지에만 씁니다.**

## 4. 작업 D 를 다시 정의합니다

### 4-1. `asset_class` 불일치 목록 (Step78 §5-1 유지)

**실측 최대 비중 자산군과 현재 `asset_class` 를 대조하십시오.**

**보고할 것입니다.**

```
789건 기본값 중 실측이 주식이 아닌 건수      ← 핵심 지표
131건 불일치 중 실측으로 판정된 건수
실측 최대 자산군과 asset_class 가 다른 전체 건수
```

**목록에는 티커, 종목명, 현재 `asset_class`, 실측 최대 자산군과 비중, `measured_unknown_pct` 를 넣으십시오.**

### 4-2. 설계 비중 대비 괴리 탐지 (신규)

**약관 비중을 직접 얻기는 어렵습니다. 다만 국내 ETF 는 이름에 비중을 명시하는 관행이 있고, 그것이 사실상 약관 비중입니다.**

```
혼합50, 채권혼합50, 국채혼합50   주식 50%
TRF3070                        주식 30%
TRF7030                        주식 70%
TRF5050                        주식 50%
```

**이름에 비중이 명시된 종목만 대상으로, 명시 비중과 실측 위험자산 비중의 차이를 산출하십시오.**

**위험자산 비중은 `measured_equity_pct + measured_reit_pct + measured_commodity_pct` 입니다.**

**임계값은 20퍼센트포인트로 하십시오.**

**근거입니다.** 주식 50퍼센트 상품의 주식이 30퍼센트 오르면 실측은 약 56.5퍼센트가 됩니다. 6.5퍼센트포인트 차이입니다. **20퍼센트포인트는 시장 변동으로 설명되지 않는 수준입니다.**

**임계값을 코드에 상수로 두고 주석에 이 근거를 남기십시오. 나중에 조정 가능해야 합니다.**

**20퍼센트포인트를 넘는 종목만 보고하십시오. 그 종목은 우리 분류가 틀렸거나 상품 성격을 잘못 이해한 것입니다.**

### 4-3. 이름에 비중이 없는 종목

**설계 비중을 모르므로 괴리를 계산할 수 없습니다.**

**대신 실측 위험자산 비중이 70퍼센트를 넘는데 안전자산으로 분류된 종목만 보고하십시오.**

**70퍼센트는 시장 변동으로 설명 불가능한 수준입니다.** `183710` 과 `341850` 이 이 조건에 걸립니다. **같은 유형이 더 있는지 찾는 것이 목적입니다.**

**50퍼센트대나 60퍼센트대는 보고하지 마십시오. 판정하지 않습니다.**
