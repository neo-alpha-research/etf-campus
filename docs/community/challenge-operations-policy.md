# 30일 ETF 판단 기준 챌린지 운영 정책

## 목적과 범위

30일 챌린지는 ETF의 비용, 공시, 위험, 연금 계좌 판단 기준을 학습하고 기록하는 프로그램입니다. 수익률, 손익, 자산 규모, 매매 횟수, 보유 종목 수, 목표 수익, 투자 비중, 상대 순위를 수집·표시·비교하지 않습니다.

## 참가 신청과 최소 정보

참가 신청에는 공개 닉네임, 챌린지 규칙 동의, 비공개 학습 기록 저장 동의가 필요합니다. 관심 계좌 유형은 `선택 안 함`을 포함한 선택 항목이며 기본 비공개입니다. 학습 주제는 교육용 선택지에서 고르며, 자유 메모는 선택 항목입니다. 자유 메모에는 실명, 연락처, 계좌번호, 금액, 수익률, 매매 계획을 입력하지 않도록 안내합니다.

## 공개성

학습 기록은 기본 비공개입니다. 이용자가 기록별로 공개를 명시적으로 선택한 경우에만 공개 피드에 표시됩니다. 공개 기록에는 공개 닉네임, 일차, 비금전 학습 지표, 이용자가 입력한 학습 메모만 표시될 수 있습니다. 관심 계좌 유형, 참가 동의, 비공개 기록은 공개하지 않습니다.

응원은 공개 기록에만 남길 수 있고, 본인 기록에는 남길 수 없습니다. 응원 수를 기준으로 한 리더보드, 인기순, 추천, 랭킹은 제공하지 않습니다.

## 자동 판정과 소명

자동 작업은 KST 기준 전일의 제출 여부를 `submitted_on_time` 또는 `not_submitted`라는 사실 상태로 기록합니다. 자동 벌점, 강제 퇴장, 공개 미달 명단, 자동 경고 발송은 제공하지 않습니다. 예외 또는 소명 요청은 운영자가 감사 기록을 남기며 수동으로 처리합니다.

## 권한과 감사

커뮤니티 권한의 단일 원천은 Supabase `community_user_roles`입니다. 기존 관리자 콘솔은 UI shell로만 재사용할 수 있으며, D1 세션만으로 커뮤니티 데이터 권한을 부여할 수 없습니다. 기수 상태 변경, 고정 공지, 소명 처리, 역할 변경, 자동 작업 결과는 관리자 감사 로그에 남깁니다.

## 탈퇴와 정리

탈퇴 후 삭제를 선택한 콘텐츠는 공개 노출을 즉시 중단하고, 보존 기간이 지난 뒤 Scheduled Worker가 service-only maintenance RPC를 통해 정리합니다. 작업은 멱등적으로 실행하고 성공·실패·재시도·처리 건수를 기록합니다. 정리 작업은 공개 endpoint에서 호출할 수 없습니다.

## 리드마그넷과 뉴스레터

현재 번들은 정적으로 제공하며 이메일을 수집하거나 뉴스레터를 발송하지 않습니다. 이메일 수집과 발송 기능은 별도 개인정보 고지, 필수/선택 동의, 보존·삭제, 수신거부, 발송 벤더와 위탁 처리 정책이 승인된 뒤 별도 변경으로 도입합니다.
