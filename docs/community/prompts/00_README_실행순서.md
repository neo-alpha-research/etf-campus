## 실행 전 선행 조건 (P0)
이 프롬프트들의 작업은 최신 `main` 브랜치 위에서 진행되어야 합니다. 과거 브랜치에서 시작하면 이미 수정된 버그와 충돌이 발생합니다.
따라서, **반드시 아래 PR들이 `main`에 먼저 병합(Merge)되었는지 확인**하십시오.

## 실행 순서
각 프롬프트는 아래 번호 순서대로 단방향으로 실행해야 합니다.

1. `01_기반정리.md` (커뮤니티 API 인코딩 복구, 잔재 파일 제거, CI 검증 스크립트 추가)
2. `02_커뮤니티기반확장.md` (공지/고정 체계 도입, 페이지네이션 확장, 모더레이션)
3. `03_시드콘텐츠등록도구.md` (일괄 등록 스크립트 작성)
4. `04_리드마그넷_뉴스레터.md` (랜딩 페이지 이메일 수집 게이트)
5. `05_기수_참가자.md` (기수 및 참가자 신청 모델)
6. `06_기록게시판.md` (챌린지 인증용 기록 게시판 뷰/폼)
7. `07_자동판정.md` (달성 판정 배치 시스템, 관리자 통계)
8. `08_결제환급_보류.md` (실행 보류: 법률 및 결제 정책 확정 후 착수)

## 추후 백로그 (P1 항목)
다음 기능들은 1기 챌린지 런칭 전후 여유가 생길 때 별도 프롬프트로 처리하십시오.
- 검색 노출 및 308 리다이렉트 (SEO 최적화)
- 댓글 알림 기능 (알림 발송 인프라 구축 후)
- 비밀번호 정책 강화 (10자 상향, 유출DB 차단)
- 카테고리별 `noindex` 분기 처리 (예: `challenge-30`, `feedback`은 개인정보 보호를 위해 색인 차단)
