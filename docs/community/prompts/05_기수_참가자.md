# Antigravity 인계 프롬프트 — Phase 4: 기수와 참가자 관리

당신은 운영 중인 `neo-alpha-research/etf-campus` 프로젝트의 백엔드 엔지니어입니다.

## 아키텍처 경계
- 이 데이터들은 모두 **Supabase (Postgres)** 에 저장되어야 합니다. (D1 사용 금지)

## 작업 명세

### 1. 스키마 확장 (마이그레이션)
새 마이그레이션 파일 `supabase/migrations/XXXXXXXXXXXXXX_community_cohorts.sql`을 작성하여 다음을 구성합니다.
- `community_cohorts` 테이블: 기수 식별자, 기수 번호, 시작일, 종료일, 모집 상태(모집중/진행중/종료).
- `community_participants` 테이블: 참가자 식별자, 회원 식별자, 기수 식별자, 신청일, 승인 상태, 결제 상태, 마일스톤 달성 상태 3종(Day 10/20/30).
- **인덱스 추가**: `community_participants` 테이블에 대해 기수 식별자, 회원 식별자 기준의 조회 인덱스를 **반드시** 생성하십시오. (성능 병목 차단)

### 2. 참가 신청 양식 UI (프론트엔드)
기수 참가 신청 페이지를 만듭니다. 
- 필수 입력란은 **3개 이하**로 제한합니다: 
  1. 퇴직연금 유형(DC / IRP / 둘 다 / 모름)
  2. 참여 목표(한 문장)
  3. 30일간 매일 기록 가능 여부(체크박스)
- 신청 화면 하단에 **미완성 도서 안내 문구**를 반드시 고정 노출하십시오.
  > "2편과 3편은 현재 집필 중이며 출간 시기가 확정되지 않았습니다. 출간 시점에 완주자에게 무료로 제공되며, 신청 시 이 점에 동의한 것으로 봅니다."
- 결제 연동은 포함하지 않습니다. (승인 상태를 운영자가 수동 전환할 수 있도록 컬럼만 만들어둠)
