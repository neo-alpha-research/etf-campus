# Antigravity 인계 프롬프트 — Phase 6: 자동 판정 배치와 관리자 화면

당신은 운영 중인 `neo-alpha-research/etf-campus` 프로젝트의 백엔드 엔지니어입니다.

## 목적
챌린지 참가자의 기록을 검사하여 달성/미달성을 매일 판정하는 시스템과, 이를 조회할 수 있는 기존 관리자 화면 확장을 목표로 합니다.

## 아키텍처 및 런타임 제약
- 커뮤니티 데이터 조회/갱신은 Supabase를 사용합니다.
- 배치 실행은 Cloudflare Workers의 Scheduled(Cron) 이벤트를 활용합니다. (pg_cron은 현재 환경에 구성되어 있지 않음이 확인되었습니다.)
- 관리자 화면의 세션 및 인증은 기존 D1 `admin_users`, `admin_user_sessions`를 100% 재사용합니다. (새 인증 구축 금지)

## 작업 명세

### 1. 자동 판정 배치 로직 (Workers Scheduled Event)
매일 **12:05 KST**에 동작하는 판정 로직을 작성합니다.
달성 판정 조건 (AND):
- 서버 시간 기준 마감 시각 이전 작성 (정시: 당일 23:59:59 KST, 지각: 익일 12:00:00 KST). 클라이언트 시간 절대 신뢰 금지.
- `day_number`가 유효하고 기수 일정과 정합.
- `body_text` 30자 이상.
- 숫자 과제가 있는 날이면 `metric_value`가 허용 범위 내 존재.
- 금칙어 미포함.
- 동일 Day에 이미 인정된 기록 없음.
- `is_author_seed`가 false일 것.
판정 결과는 `community_participants` 또는 별도 로그 테이블에 변경 불가 상태로 기록(판정 시각, 규칙 버전, 제출 시각, 마감 시각 포함).

### 2. 투명성 및 민원 방지 (알림)
- 미달성 확정 시 즉시 이메일 발송.
- 마일스톤 달성까지 여유 일수가 2일 이하일 때 경고 발송.
**주의**: 현재 `scripts/newsletter`에는 MTA(발송) 인프라가 없습니다. 알림 로직은 외부 발송 API(예: Resend, Postmark) 호출부 인터페이스만 구성하고, 상세 구현은 TODO로 남겨두십시오.

### 3. 관리자 화면 (기존 콘솔 확장)
- 기수별 참가자 목록, 구간별 제출 수, 마일스톤 달성 여부, 지급 처리 상태를 표 형태로 노출합니다.
- 운영자의 수동 개입 인터페이스: "마감 일괄 연장" (장애 시), "소명 접수 승인/반려" 기능만 제공.
