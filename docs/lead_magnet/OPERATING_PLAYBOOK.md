# ETF Campus 리드 마그넷 월간 발행 매뉴얼

목적: 유료 API 없이, 무료 공공데이터와 운용사 공식 공시만으로 3페이지 ETF 비교 PDF를 매월 갱신한다.

## 발행 기준일

- 발행 기준일(D): 해당 월 마지막 거래일. 가격이 없으면 직전 거래일.
- 가격 지표: 금융위원회 `증권상품시세정보` API의 거래소 시장가격 종가.
- 보유종목: 운용사 공식 상품 페이지 또는 구성종목 PDF. 가격 기준일과 다르면 각각의 기준일을 PDF에 별도 표시.
- 비용: 금융투자협회 공시 또는 운용사 최신 공식 비용자료. 총보수만 단독 표기하지 않는다.

## 매월 작업 순서

1. **기준일 확정**
   - 휴장 여부를 확인하고 D를 기록한다.
   - API 키는 셸 세션의 `DATA_GO_KR_SERVICE_KEY` 환경변수에만 임시 설정한다. 코드·CSV·PDF에 키를 저장하지 않는다.

2. **가격 데이터 수집**
   - 페이지 2: `scripts/collect_income_page2_prices.py`
   - 페이지 3: `scripts/collect_page3_prices.py`
   - 각 종목의 최초·최종 관측일과 관측치 수를 확인한다.
   - 상장 후 1년 미만 상품은 `1년 MDD` 대신 `상장 후 MDD`로 표시한다.

3. **지표 계산**
   - 페이지 3: `scripts/calculate_page3_metrics.py`
   - YTD·3개월 수익률 및 MDD는 시장가격·분배금 제외로 유지한다.
   - 분배금까지 반영한 총수익률은 지급일·재투자 가정이 완결된 경우에만 별도 표기한다.

4. **운용사 공시 대조**
   - 페이지 1: 비용 자료의 회계연도·발행일을 기록한다.
   - 페이지 2: 최근 12개월 실제 분배금 지급일·지급액을 원장에 기록한다.
   - 페이지 3: TOP 5 종목과 비중, 구성 기준일, 상위 5개 비중 합계를 기록한다.
   - 공식 원문을 확보하지 못한 숫자는 추정하지 않는다. `공식 이력 수집 중`, `부분 확인`, 또는 비교군 제외로 표기한다.

5. **표현 검증**
   - `원금 방어`, `확정 수익`, `추천`, `최고` 같은 단정 표현을 쓰지 않는다.
   - MDD에는 ‘관측기간·시장가격·분배금 제외’를 명시한다.
   - 전략·지수·상품명 변경 이력이 있으면 변경일과 `참고용` 배지를 함께 표시한다.
   - 가격 기준일과 보유종목 기준일이 다르면 둘 다 표기한다.

6. **PDF 생성·병합**
   - `scripts/create_lead_magnet_page1.py`
   - `scripts/create_lead_magnet_page2.py`
   - `scripts/create_lead_magnet_page3.py`
   - `scripts/merge_lead_magnet_pdf.py`
   - 최종본은 `output/pdf/etf-campus-3-page-etf-lead-magnet.pdf`이다.

7. **발행 전 체크**
   - [ ] 3페이지 모두 A4 가로형인지 확인
   - [ ] 표·각주·페이지 번호가 잘리지 않는지 PNG 렌더링 확인
   - [ ] PDF 페이지 수가 정확히 3인지 확인
   - [ ] PDF 안에 API 키·개인정보·내부 파일 경로가 없는지 확인
   - [ ] 기준일, 출처, 분배금 포함 여부, 예외 표기가 최신인지 확인

## 예외 처리 원칙

| 상황 | 처리 |
| --- | --- |
| 공공 API가 일시 실패 | 재시도 후 수집일을 기록하고, 해결 전 발행하지 않음 |
| 운용사 공시 기준일이 오래됨 | `구성 기준일 지연`으로 표시하거나 해당 ETF 제외 |
| 전략 변경 발생 | 변경일 명시, 장기 성과는 참고용 처리 |
| 공식 데이터 미확보 | 빈칸을 채우지 않고 `수집 중` 또는 `보류` 표기 |
| API 키 노출 의심 | 즉시 재발급하고 기존 키를 폐기 |
