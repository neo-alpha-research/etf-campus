## 0. 이 지시서의 전제 — 이미 실증된 사실 5가지

아래는 추정이 아니라 **원본 파일과 실제 API 호출로 확인된 결과**입니다. 재조사하지 말고 전제로 사용하십시오.

**전제 1. OpenDART `document.xml`로는 투자설명서 본문을 얻을 수 없습니다.**
`20260330000048`(최초 투자설명서)을 실제 호출한 결과: ZIP 내부 파일 1개, 본문 텍스트 7,435자, `<TITLE>[ 본 문 ]</TITLE>` 이후 **내용 없음**. 저장된 10건 전부 동일합니다. 본문·신탁계약서는 OpenDART가 노출하지 않는 첨부문서입니다.
→ **위험평가액·약관 조항을 OpenDART API로 확보하려는 시도를 반복하지 마십시오.**

**전제 2. 저장된 DART 10건은 전부 `정정신고서`이고, 그중 1건만 증거가 됩니다.**
`20260630000020`(284430)만 정정 항목이 투자한도라 다음 문구를 담고 있습니다.
```
8. 집합투자기구의 투자대상
   가. 투자대상주식: 40% 이하  →  가. 투자대상주식: 50% 미만
```
나머지 9건은 정정 항목이 달라 해당 문구가 없습니다.

**전제 3. 협회 미매칭 95건은 KOFIA 원본에 존재합니다. 조인 실패입니다.**
30MB XML의 상장지수 레코드 1,155건 중 `kofia_fund_types.csv`가 쓰지 않은 표준코드가 **정확히 106건** 남아 있습니다. 이 106건이 미매칭 95건의 상대편입니다. 실패 원인은 열거 가능한 명칭 표기 차이입니다.

| 원인 | 마스터 표기 | KOFIA 표기 |
|---|---|---|
| 운용사 prefix | `RISE 대형고배당10TR` | `KBRISE대형고배당10TotalReturn…` |
| 브랜드 접두 | `HANARO 200TR` / `마이티 200TR` / `파워 200` / `ACE …` / `TIME …` / `FOCUS …` | `NH-AmundiHANARO…` / `DB마이티…` / `교보악사파워…` / `한국투자ACE…` / `타임폴리오TIME…` / `브이아이FOCUS…` |
| TR 표기 | `…TR` | `…TotalReturn` |
| 플러스 기호 | `TIGER 현대차그룹플러스` | `미래에셋TIGER현대차그룹+` |
| XML 엔티티 | `KODEX 미국S&P500선물(H)` | `…미국S&amp;P500선물…` |
| 토큰 순서 | `KODEX TDF2050액티브 적격` | `삼성KODEX적격TDF2050액티브` |
| 단어 누락 | `TIGER 12월자동연장금융채…` | `미래에셋TIGER12월**만기**자동연장금융채…` |
| 리브랜딩 | `TIGER 미국필라델피아반도체레버리지(합성)` | `미래에셋TIGER필라델피아반도체레버리지…` |

이 8개 규칙을 적용한 시제품 매처로 4건이 이미 자동 매칭되었습니다(315960, 361580, 332930, 0112X0 — 전부 TR↔TotalReturn 규칙). **나머지는 규칙 보강 + 106건 후보 목록과의 1:1 육안 확정으로 처리 가능합니다.**

**전제 4. 106건 후보 중 단순유형(주식형/채권형)이 39건입니다.**
주식형 31건 + 채권형 8건. 이들은 협회 단순유형만으로 **E3 단독 승격**이 가능합니다.

**전제 5. 채권혼합형 약관 개정(40%→50%)은 업계 전반의 진행 중인 물결입니다.**
- 삼성자산운용: `KODEX 200미국채혼합` → `KODEX 200미국채혼합50`, 2026-06-30, 주식한도 40% 이하 → 50% 미만
- 미래에셋자산운용: `TIGER 미국나스닥100채권혼합Fn` → `TIGER 미국나스닥100채권혼합50`, 2026년 4월, 동일
- 근거: 2023년 퇴직연금감독규정 제11조 개정(금융위원회고시 제2023-56호)

→ 큐의 채권혼합 37건 중 상품명에 `50`이 붙은 것들은 **이미 개정을 마친 상품**입니다. 정정신고서가 존재합니다.

## 1. 최우선 과제 — 협회 펀드유형의 법적 의미를 확정하십시오

**이것이 419건 중 가장 큰 덩어리를 한 번에 푸는 열쇠입니다. 다른 작업보다 먼저 하십시오.**

### 확인해야 할 명제

```
[명제] 금융투자협회 펀드유형 "혼합채권형"의 분류 기준인 "주식 50% 미만"은
       실제 보유비중이 아니라 '약관·정관상 주식 최고 편입한도'를 기준으로 한다.
```

이 명제가 참이면 다음이 **논리적으로 직결**됩니다.

```
KOFIA 유형 = 혼합채권형
  ⟹ 약관상 주식 투자한도 < 50%
  ⟹ 퇴직연금감독규정 제11조 제1항 제5호 전단 요건 충족
  ⟹ 안전자산 100%  (단, 후단 요건 별도 확인)
```

두 임계값이 **50%로 정확히 일치**한다는 점이 이 논증의 핵심입니다. 우연이 아니라 2023년 고시 개정이 협회 분류 경계에 맞춘 결과입니다.

### 확인 방법

금융투자협회 법규정보시스템(`law.kofia.or.kr`)에서 다음을 찾아 **원문을 확보**하십시오.
- 「금융투자회사의 영업 및 업무에 관한 규정」 중 펀드 유형 분류 조항
- 또는 「금융투자회사의 컴플라이언스 매뉴얼 Ⅲ편(자산운용)」의 펀드 분류 기준
- 또는 협회 전자공시서비스(dis.kofia.or.kr)의 펀드유형 정의 안내

확보한 원문은 `data/regulatory/sources/statutes/`에 저장하고 `statute_registry.csv`에 `KOFIA_FUND_TYPE_STD` 로 등재하십시오.

### 분기 처리 — 이 부분을 반드시 지키십시오

- **원문에 "약관상" 또는 "정관상" 기준임이 명시된 경우** → 아래 §2 매핑표를 E3로 적용, 대량 승격
- **원문이 실제 보유비중 기준이거나 불명확한 경우** → **승격하지 말고 중단**하고 그 사실을 보고하십시오. 정황만으로 48건을 승격하는 것은 배치1과 같은 실수입니다.

### 두 번째 요건은 별도입니다

제11조 제1항 제5호 후단: **"투자적격등급 이외의 채무증권에 대한 투자한도가 100분의 30을 초과하는 것은 제외"**

협회 유형으로는 커버되지 않습니다. 다음 규칙으로 분기하십시오.
- 기초지수·상품명이 국채·통안채·투자적격 회사채(예: `종합채권(AA-이상)`)로 명시 → 후단 요건 충족으로 인정
- 하이일드·신흥국채·크레딧·뱅크론이 명시되거나 불명확 → **별도 확인 큐**로 분리, 승격 보류

- **혼합채권형 37 + 혼합채권파생형 11** → 안전자산 100% (§1 확인 + 후단 요건 통과 시)
- **혼합주식파생형 8 + 주식파생형 162** → **"안전자산 아님"은 지금 즉시 확정**됩니다. 협회 분류상 주식 50% 이상이므로 제11조 제1항 제5호에 해당할 수 없습니다. 위험자산 70%인지 편입 불가인지만 Gate 0으로 가리면 됩니다.
- **특별자산 6** → 파생이 아니므로 위험평가액 40% 룰의 적용 대상이 아닙니다. 위험자산 70% 확정.
- **부동산 10** → 협회가 `부동산`으로 분류한 것 자체가 부동산집합투자기구라는 공적 표시입니다. 제11조 제2항 제4호로 원칙 불가, 시행령 제240조 제4항 제2·3호 단서만 확인하십시오.

**중요**: "안전자산 아님 확정"도 `pension_limit` 확정에 기여하는 진짜 진전입니다. 76건 안전자산 주의 그룹을 줄이는 것이 이 작업의 실질 목표입니다.

## 3. 실행 순서

### Step A — 선행 정정 (선행 문서 §9 Step 1과 동일, 미완료 시 여기서 완료)

배치1 9건 회수, 임계값 40%→50% 미만, 제12조→정본 조문, `statutory_basis` 공란 165행. **이것 없이 아래를 진행하면 오염이 확산됩니다.**

### Step B — 협회 분류기준 원문 확보 (§1)

성공/실패를 명시적으로 보고하십시오. 실패 시 Step D로 건너뜁니다.

### Step C — 매핑표 전면 교체 및 일괄 판정 (§2)

`kofia_type_mapping.py` 재작성 → 큐 재판정 → 승격.
`evidence_grade = E3`, `source_type = 협회공시대조`, `evidence_ref`에 **해당 종목의 KOFIA 표준코드와 펀드유형 원문**을 기록하십시오.

### Step D — 미매칭 95건 재매칭 (전제 3·4)

1. 30MB XML에서 상장지수 1,155건 파싱 → `kofia_fund_types.csv` 기사용 표준코드 제외 → 후보 106건 확보
2. 정규화 규칙 8종 적용 (전제 3 표)
3. 자동 매칭 결과와 **잔여 후보를 나란히 출력**하여 1:1 대응이 유일한 건만 확정
4. **1:1이 아닌 건은 승격하지 말고 미해결로 남기십시오.** 억지 매칭이 가장 위험합니다.
5. 매칭 성공분은 §2 매핑표로 재판정. 단순유형 39건은 즉시 승격.
6. 최종 잔여분은 KOFIA에 애초에 없는 신규 상장분입니다(최대 12건). KRX 상장공시로 별도 처리.

### Step E — 레버리지·인버스 추적배수 확정

`.dev.vars`의 `KRX_OPEN_API_KEY`로 KRX ETF 기본정보를 조회해 **추적배수**를 확보하십시오.
- 배수가 1배 초과 또는 음수 → 제9조 제1항 제2호 마목 단서에서 배제 → 편입 불가 확정 (`evidence_grade = E0`)
- 판정키는 추적배수입니다. 상품명의 `레버리지`/`인버스`/`2X`는 보조 지표일 뿐입니다.
- 명칭에 `선물`이 있으나 1배수인 상품은 레버리지가 아닙니다. 별도 그룹으로 분리하십시오.

### Step F — DART 정정신고서 스윕 (채권혼합 개별 확증)

Step C가 §1 실패로 막힌 경우의 **대체 경로**이자, 성공한 경우의 **교차검증**입니다.

1. OpenDART `corpCode.xml`로 운용사 corp_code 확보 (삼성·미래에셋·KB·한국투자·키움·신한·한화·NH아문디·DB·교보악사 등)
2. `list.json`으로 각 운용사의 2023-11-16 이후 투자설명서 정정신고 목록 조회
3. 각 rcpNo의 `document.xml` 본문에서 정정 대비표 추출
   ```
   패턴: 투자대상\s*주식[:\s]*([0-9]+)\s*%?\s*(이하|미만)   ← 정정 전/후 2회 등장
   ```
4. 정정 후 값이 `50% 미만`이면 `PSR_ART11_1_5` E2 승격, `evidence_quote`에 **원문 문구 그대로** 기록
5. 정정신고서 1건이 여러 종목을 포함하는 경우가 많으므로 문서 수는 종목 수보다 훨씬 적습니다.

**전제 1을 기억하십시오.** 최초 투자설명서 rcpNo로는 아무것도 얻지 못합니다. 정정신고서만 대상으로 하십시오.

### Step G — 잔여 파생군 처리 방침
