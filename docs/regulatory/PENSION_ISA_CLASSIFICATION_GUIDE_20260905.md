10건 모두 본문이 `[ 본 문 ]` 플레이스홀더에서 끊깁니다. 받아온 것은 **투자설명서 표지**이지 본문이 아닙니다.

그런데 원장 `pension_verification_ledger.csv`의 note는 10건 전부 이렇게 적혀 있습니다.

```
DART 투자설명서: 약관상 주식 투자한도 50% 미만 채권혼합형 (퇴직연금감독규정 제11조 제1항 제5호)
DART 투자설명서: 1배수 금리액티브 장외파생 100% 한도 적격 (퇴직연금감독규정 제9조 제1항 제2호 마목)
```

**증거 문서에 없는 사실을 증거로 인용했습니다.** 파일은 실존하고 해시도 맞고 rcpNo도 진짜입니다. 그래서 `validate_evidence_integrity.py`가 PASS를 냈습니다. 이것이 곧 무결성 검증기의 구조적 공백입니다.

> **무결성 검증기는 증거의 출처(provenance)만 검사하고, 증거의 충분성(sufficiency)은 검사하지 않습니다.**
> E1~E5는 "파일이 있는가 / 해시가 맞는가 / URL이 가짜가 아닌가"만 봅니다. "그 파일 안에 그 문장이 있는가"는 아무도 보지 않습니다.

### 유일한 진짜 증거는 284430 1건입니다

`20260630000020.xml` 안에는 실제 문구가 있습니다.

```
8. 집합투자기구의 투자대상
   가. 투자대상주식: 40% 이하   →   가. 투자대상주식: 50% 미만
```

이건 완전한 증거입니다. 정정 전/후가 문서 안에 명시되어 있습니다.

### 왜 1건만 통했는가 — 그리고 이것이 419건 전략의 분기점입니다

284430만 **정정신고서**였고, 마침 정정 항목이 투자한도였기 때문입니다.

OpenDART `document.xml`은 문서 유형에 따라 반환 내용이 다릅니다.
- **정정신고서**: 정정 전/후 대비표를 본문에 담음 → 투자한도 변경이면 그대로 증거
- **최초 투자설명서**: 표지만 반환, 본문은 ZIP 내 별도 첨부 파일

즉 **현재의 DART 수집 방식으로는 419건을 깰 수 없습니다.** 10건 중 9건이 실패한 것은 우연이 아니라 방법의 구조적 한계입니다. 이 사실을 인정하지 않으면 419건을 같은 방식으로 시도해 같은 비율로 실패하게 됩니다.

### 즉시 조치

1. 9건(`0177N0`, `475630`, `357870`, `449170`, `448330`, `0162Z0`, `477080`, `423160`, `459580`)을 **검증 원장에서 회수**하고 미검증 큐로 되돌릴 것.
   - 검증 원장: 748행 → **739행**
   - `verified` 지표: 748 → **739 (63.3%)**
   - `etf_master_draft.csv`의 해당 9건 `pension_verified`를 `N`으로 복원
2. 284430 1건은 유지하되 note를 실제 문구로 교체:
   `DART 정정신고서(rcpNo 20260630000020) 제2부 8. 투자대상 "가. 투자대상주식: 40% 이하 → 50% 미만" 대조`
3. **지표를 후퇴시키는 것을 실패로 보지 마십시오.** 63.2% → 64.1%의 상승분보다, 63.3%가 전부 진짜라는 사실이 훨씬 큰 자산입니다.

## 2. F-2 — 주식한도 기준이 현행 법령과 다릅니다

### 법령 원문 (`data/regulatory/sources/statutes/퇴직연금감독규정_20260905.txt`)

```
제11조(적립금 운용방법 등) ①
5. 약관 또는 정관상 주식의 투자한도가 집합투자기구 자산총액의 100분의 50 미만인
   증권형집합투자증권등(투자적격등급 이외의 채무증권에 대한 투자한도가
   100분의 30을 초과하는 것은 제외한다) <개정 2023. 11. 16.>
```

**50% 미만**입니다. 40%가 아닙니다. 금융위원회고시 제2023-56호(2023-11-16)로 상향되었고, 이 사실은 `statute_registry.csv`에 이미 `FSC_NOT_2023_56`으로 정확히 기록되어 있습니다.

### 그런데 파이프라인 전체가 아직 40%입니다

| 위치 | 현재 값 |
|---|---|
| `pension_unverified_queue.csv` 37건 사유 | "주식 편입한도 **40% 이하** 여부 약관 확인 필요" |
| `prospectus_mixed_bonds_registry_UNVERIFIED.csv` | `equity_limit_cap` = "**40% 이하** (30% 타깃)" |
| `pension_regulatory_engine.py:209,212` | "주식 **50% 이하**" (미만이 아니라 이하) |

세 곳이 서로 다른 값을 씁니다. 그리고 **본인들이 승격한 284430의 정정신고서가 바로 "40% 이하 → 50% 미만" 개정을 증명하는 문서**입니다. 증거를 손에 쥐고 반영을 안 한 상태입니다.

### 이것이 왜 치명적인가

`holdings_measured_composition.csv` 기준 채권혼합형 37건의 실측 주식비중입니다.

```
47~50% 구간 밀집:  0019K0(47.49) 435420(48.34) 490490(49.92) 472170(47.28)
                  0182S0(49.83) 447620(48.98) 0080X0(47.36) 0178H0(48.34)
                  0186S0(49.22) 0184E0(48.91) 0049K0(48.47) 0192S0(48.58)
                  0203D0(49.54) 0216K0(49.98) 0220A0(49.82) 0104H0(42.71)
                  438080(42.70) 438100(43.36) 183700(40.86)
```

**40% 기준이면 이 그룹 대부분이 탈락하고, 50% 미만 기준이면 대부분 통과합니다.** 판정 방향이 정반대로 갈립니다. 76건 안전자산 주의 그룹의 절반이 여기 걸려 있습니다.

### `50% 이하`가 아니라 `50% 미만`입니다

`pension_regulatory_engine.py:209,212`의 "50% 이하"는 경계값을 잘못 잡습니다. 약관 주식한도가 정확히 50%인 상품은 **탈락**입니다. `<= 50` 이 아니라 `< 50` 으로 고칠 것.

### 아무도 검사하지 않는 두 번째 요건

제11조 제1항 제5호 괄호: **"투자적격등급 이외의 채무증권에 대한 투자한도가 100분의 30을 초과하는 것은 제외"**

하이일드 채무증권 한도 30% 초과 여부는 파이프라인 어디에도 없습니다. 주식한도만 통과하면 안전자산으로 넘기고 있습니다. 하이일드·신흥국채 슬리브를 가진 채권혼합형이 오분류될 수 있습니다.

## 3. F-3 — 제12조는 자산분류 조항이 아닙니다

### 법령 원문

```
제12조(집중투자위험 방지) 집중투자로 인한 위험을 방지하기 위해 ...
1. 동일 법인이 발행한 증권(집합투자증권은 제외한다)에 대한 투자한도 ...
   나. 확정기여형퇴직연금 및 개인형퇴직연금 : 가입자별 적립금의 100분의 30 이내
2. 동일 계열기업군 ... 나. ... 100분의 40 이내
```

제12조는 **가입자 계좌 단위의 동일법인·동일계열 집중투자 한도**입니다. 조문 본문이 `(집합투자증권은 제외한다)`라고 명시하므로 **ETF에는 애초에 적용되지 않습니다.**

반면 `pension_audit_ledger.csv`와 `statute_registry.csv`는 제11조·제9조로 **정확합니다.** 원장은 맞고 큐·레지스트리·문서는 틀린 **이중 상태**입니다. `validate_pension_consistency.py`가 세 원장의 행 수 일치만 보고 조문 정합은 보지 않기 때문에 0 violations가 나옵니다.

### 추가 — `audit_ledger`의 `statutory_basis` 공란 165건

```
620 MOEL_WRBA_RULE_ART10_1_2   167 PSR_ART9_1_2   165 (공란)
141 PSR_ART11_1_4   56 PSR_ART11_1_5   13 PSR_ART11_1_9   5 PSR_ART11_1_6
```

"전수 1,167행 법령 근거 매핑 갱신"이라고 보고했으나 165행에 근거가 없습니다.

### 추가 — PSR_ART9_1_2를 안전자산 근거로 쓴 것은 조문 오배정

합성 금리형 6건에 `PSR_ART9_1_2`(제9조 제1항 제2호 마목)를 **100% 안전자산** 근거로 달았습니다. 그러나 두 조문의 역할이 다릅니다.

- **제9조**: 퇴직연금에 **편입할 수 있는 증권의 종류** — 적격성(불가/가능) 판정
- **제11조 제1항**: **투자위험을 낮춘 운용방법** — 안전자산 100% 판정

합성 1배수 ETF는 제9조 마목 단서로 **편입 적격**이 될 뿐, 그것만으로 안전자산이 되지 않습니다. 100% 안전자산이 되려면 제11조 제1항 각 호 중 하나에 별도로 해당해야 합니다. CD금리·KOFR 합성 ETF는 약관상 주식 투자한도가 0%이므로 **제11조 제1항 제5호**로 걸립니다.

→ **근거를 이중 기재할 것**: `PSR_ART9_1_2`(편입 적격) + `PSR_ART11_1_5`(안전자산 100%)

## 4. 추가 관찰 3건

### O-1. 실측 데이터를 규정 판정에 쓸 수 없는 상태입니다

`holdings_measured_composition.csv`에서 `measured_equity_pct + measured_bond_pct`가 100을 넘는 행이 다수입니다.

```

0220A0 KIWOOM 현대차그룹TOP3     eq=49.82 + bd=51.67 = 101.49
```

정규화되지 않은 값입니다. 그리고 애초에 **법령 테스트는 "약관상 투자한도"이지 실측 보유비중이 아닙니다.**

> **원칙: 실측치는 약관 한도의 대체재가 아닙니다.**
> 실측은 (a) 작업 우선순위 정렬, (b) 약관과 실측이 어긋나는 이상 탐지 — 이 두 용도로만 쓸 것.
> 실측치를 근거로 `pension_verified=Y`를 부여하는 것은 금지합니다.

### O-2. 명칭 기반 판정이 엔진에 남아 있습니다


```
  │        단서) 자본시장법 시행령 제240조 제4항 제2호·제3호 방법이고
  │              가~라목 이해상충에 해당하지 않으면 투자 가능
  ├ 5호  증권예탁증권(DR)                      → 불가
  └ 1호·2호는 ETF 자체에는 비적용 (편입자산 확인)
        ↓ 통과
[Gate 2] 안전자산 100% 여부 — 제11조 제1항
  ├ 4호  원리금보장 운용방법 및 제1~3호 증권에만 투자      → 안전자산 100%
  ├ 5호  약관상 주식 투자한도 < 50%  AND
  │        투자적격등급 이외 채무증권 투자한도 <= 30%     → 안전자산 100%
  ├ 6호  자본시장법 제229조 제5호 단기금융집합투자기구(MMF) → 안전자산 100%
  └ 9호  적격 TDF (투자목표시점 명시 + 감독원장 기준 충족)  → 안전자산 100% (DC/IRP 한정)
        ↓ 미해당
[Gate 3] 위험자산 — 시행령 제26조 제1항 제2호 가목 + 시행규칙 제10조 제1항 제2호
  └ 가입자별 전체 적립금의 70% 한도
```

### 조문 매핑표 (이 표 밖의 조문을 쓰지 마십시오)

| 판정 결과 | statute_id | 조문 |
|---|---|---|
| 편입 불가(레버리지/인버스/위험평가액 초과) | `PSR_ART9_1_2` | 감독규정 제9조 제1항 제2호 마목 |
| 편입 불가(사모/부동산집합투자기구/DR) | `PSR_ART11_2` | 감독규정 제11조 제2항 |
| 안전자산 100%(채권형) | `PSR_ART11_1_4` | 감독규정 제11조 제1항 제4호 |
| 안전자산 100%(주식한도 50% 미만 혼합) | `PSR_ART11_1_5` | 감독규정 제11조 제1항 제5호 |
| 안전자산 100%(MMF) | `PSR_ART11_1_6` | 감독규정 제11조 제1항 제6호 |

> **합성 ETF는 근거 두 개를 함께 답니다.** `PSR_ART9_1_2`(편입 적격) + `PSR_ART11_1_x`(안전자산 등급). 제9조 단독으로 안전자산을 주장하지 마십시오.

## 6. 증거 등급 체계 (E-Grade) — 신설

무엇이 증거인지 정의되어 있지 않아 F-1이 발생했습니다. 아래 등급을 원장에 `evidence_grade` 컬럼으로 신설합니다.

| 등급 | 정의 | 승격 가능 |
|---|---|---|
| **E0** | 법령 문언만으로 결정 (레버리지·인버스 배제 등). 개별 문서 불필요 | 단독 가능 |
| **E1** | 투자설명서·집합투자규약 **본문**에서 해당 조항 문구를 원문 인용 | 단독 가능 |
| **E2** | 정정신고서 정정 전/후 대비표에 해당 항목이 명시 | 단독 가능 |
| **E3** | KOFIA 공시 펀드유형. **단순유형(주식형/채권형)만 유효.** 파생형·혼합형은 불충분 | 단순유형 한정 |
| **E4** | 판매사(증권사) 퇴직연금 편입 유니버스. 실무 확인이며 법령 근거 아님 | 교차검증 전용 |
| **E5** | 실측 보유비중(`holdings_measured_composition.csv`) | **승격 금지** |

**승격 규칙**
- `pension_verified = Y` 부여는 **E0, E1, E2 단독** 또는 **E3 + E4 조합**에서만.
- E5는 단독으로도 조합으로도 승격 근거가 될 수 없습니다. 트리아지와 이상탐지 전용입니다.
- E1/E2는 반드시 `evidence_quote` 컬럼에 **원문 문구를 그대로** 기록합니다. 요약·의역 금지.

### E6 — 증거 충분성 검사기 (신설 필수)

`validate_evidence_integrity.py`에 다음 검사를 추가합니다. **이것이 F-1의 재발 방지 장치입니다.**

```
S5(신설): evidence_ref가 로컬 파일이고 evidence_grade가 E1/E2인 경우,
          note가 주장하는 사실의 핵심 키워드가 해당 파일 본문에 실제로 존재해야 한다.

  주장 유형              → 파일 본문에 있어야 하는 문자열(택1)
  ─────────────────────────────────────────────────────────
  주식 투자한도           → "투자대상주식" | "주식의 투자한도" | "100분의 50"
  파생 위험평가액          → "위험평가액"
  사모/재간접             → "사모" | "집합투자증권에 투자"
  부동산집합투자기구        → "부동산집합투자기구" | "제240조"

  미충족 시 violation. 해당 행은 자동으로 pension_verified=N 으로 강등.
```

현재 배치1 10건에 이 검사를 적용하면 **9건이 violation**으로 걸립니다. 그것이 정상 동작입니다.

## 7. 419건 트랙 분해 및 실행 순서

수확률이 높고 비용이 낮은 순서로 배열했습니다.

| 트랙 | 대상 | 건수 | 필요 증거 | 난이도 |
|---|---|---|---|---|
| **T-H** | 협회 미매칭 | 95 | 조인 복구 (규제 문제 아님) | 하 |
| **T-A** | 레버리지·인버스 | ~90 | E0 | 하 |
| **T-B** | 합성(Synthetic) 1배수 | ~25 | E0 + E1 | 하 |
| **T-C** | 채권혼합형 | 37 | E2 (정정신고서) | 중 |
| **T-G** | 특별자산(실물) | 9 | E1 | 중 |
| **T-E** | 재간접형 | 21 | E1 | 중 |
| **T-F** | 부동산·리츠 | 14 | E1 | 중 |
| **T-A'** | 1배수 선물형 (레버리지 아님) | ~26 | E1 (위험평가액) | 상 |
| **T-D** | 파생 위험자산(커버드콜 등) | ~102 | E1 (본문 필요) | 상 |

### T-H — 협회 미매칭 95건 : 이건 규제 문제가 아닙니다

`kofia_fund_types.csv` 1,072행 vs 마스터 1,167행 = **정확히 95건 차이**입니다. 우연이 아닙니다.

현재 종목명 문자열로 조인하고 있습니다. `kofia_fund_types.csv`에는 이미 `standard_code`(ISIN) 컬럼이 있습니다. **ISIN 조인으로 바꾸면 상당수가 즉시 해결됩니다.** 잔여분은 신규 상장분이므로 KRX 상장공시로 보완합니다.

95건 중 `주식형`·`채권형` 단순유형으로 확인되는 것은 E3 단독 승격이 가능합니다. 가장 싼 승격 경로입니다.

### T-A — 레버리지·인버스 : 명칭이 아니라 추적배수로 판정하십시오

Gate 0의 법문은 "목표로 하는 **지수의 변화에 1배를 초과하거나 음의 배율로 연동**"입니다. 상품 명칭이 아닙니다.

- 1차 키: 투자설명서 표지 또는 KRX 상장 ETF 기본정보의 **추적배수**
- 보조 키: 명칭의 `레버리지` / `인버스` / `2X` / `-1X`
- **주의**: 명칭에 `선물`이 들어가는 1배수 상품(원자재 선물 ETF 등)은 레버리지가 아닙니다. 이들은 T-A'로 분리해 **위험평가액 40% 초과 여부**로 별도 판정해야 합니다. 현재 116건이 뭉뚱그려져 있으므로 먼저 두 그룹으로 나누십시오.

### T-B — 합성 1배수 : Gate 0 단서의 직접 적용 대상

`holdings_measured_composition.csv`의 `is_synthetic = Y`이고 추적배수 1배·비인버스면 제9조 제1항 제2호 마목 단서로 **위험평가액 한도 100%** → 편입 적격(E0).

안전자산 등급은 별도입니다. CD금리·KOFR 등 금리·파킹형은 약관상 주식 투자한도가 0%이므로 제11조 제1항 제5호로 안전자산 100%. **근거 두 개를 함께 기재합니다.**

### T-C — 채권혼합형 37건 : 정정신고서 스윕이 정답입니다

284430 사례가 방법을 알려줍니다. 2023-56호 개정(주식한도 40% 이하 → 50% 미만)에 맞춰 운용사들이 약관을 **순차 개정 중**이고, 그 개정이 정정신고서에 대비표로 남습니다.

```
권장 절차
1. OpenDART list.json 으로 운용사별(삼성/미래에셋/KB/한투/키움/신한/한화 등)
   2023-11-16 이후 투자설명서 정정신고 목록 조회
2. 각 rcpNo 의 document.xml 본문에서 "투자대상주식" 정정 대비표 정규식 추출
   패턴 예: 투자대상주식[:\s]*([0-9]+)%\s*(이하|미만).*?투자대상주식[:\s]*([0-9]+)%\s*(이하|미만)
3. 추출된 "정정 후" 값이 50% 미만이면 PSR_ART11_1_5 로 E2 승격
```

운용사가 시리즈를 묶어 정정하는 경우가 많아 **문서 1건에 여러 종목이 잡힐 가능성**이 높습니다. 37건 대비 문서 수는 훨씬 적을 것으로 예상합니다.

동시에 **제11조 제1항 제5호의 두 번째 요건**(투자적격등급 이외 채무증권 한도 30% 초과 제외)도 같은 문서에서 확인하십시오. 현재 아무도 검사하지 않고 있습니다.

### T-D — 파생 위험자산 102건 : 병목은 판정이 아니라 수집 방식입니다

위험평가액 40% 판정은 표지로 불가능하고 본문이 필요합니다. 그런데 현재 수집기가 받아오는 `document.xml`은 표지만 담고 있습니다.

**수집기를 먼저 고쳐야 합니다.** OpenDART `document.json`은 ZIP을 반환하며 본문은 내부 별도 파일에 있습니다. ZIP 전개 후 본문 파일을 선택하는 로직이 추가되기 전까지 이 트랙은 착수하지 마십시오.

그 전까지 102건은 `pension_confidence = 낮음`, 위험자산 70% 잠정 유지, `pension_verified = N`으로 둡니다. 커버드콜의 옵션 매도 상계로 순위험평가액이 40% 이내라는 것은 **일반론이지 개별 상품의 확인된 사실이 아닙니다.** 추정으로 승격하지 마십시오.

### T-F — 부동산 14건 : 먼저 조문 적용 대상인지부터 가리십시오

제11조 제2항 제4호는 **부동산집합투자기구**(자본시장법 제229조 제2호)가 발행한 집합투자증권을 금지합니다. 국내 상장 리츠 **주식**에 투자하는 ETF는 통상 증권집합투자기구이므로 이 조문의 적용 대상이 아닙니다.

1차 키는 `kofia_fund_type`이 `부동산`인지 `주식형`인지입니다. 부동산집합투자기구로 확인된 경우에만 단서(시행령 제240조 제4항 제2호·제3호 방법 + 가~라목 이해상충 비해당)를 따집니다.

## 8. ISA 판정 축 — 현재 사실상 비어 있습니다

`pension_regulatory_engine.py`의 ISA 로직은 전 종목 `isa_eligible = 가능`, 레버리지·인버스만 `isa_education_required = Y`입니다.

법령상 틀리지 않습니다. 중개형 ISA는 국내 증권시장 상장 ETF를 전 종목 편입할 수 있습니다. 그러나 **1,167건이 전부 같은 값이므로 판정 필드로서 정보량이 0입니다.** 이 상태로는 "ISA 구분 기준"이라고 부를 수 없습니다.

### ISA의 실제 구분축은 편입 가부가 아니라 과세 구조입니다

| 유형 | 계좌 밖 과세 | ISA 실익 |
|---|---|---|
| 국내주식형 ETF | 매매차익 **비과세**, 분배금만 배당소득세 | 낮음 (분배금 한정) |
| 국내상장 해외주식형·채권·원자재·리츠·커버드콜 ETF | 매매차익·분배금 모두 **배당소득세 과세** | 높음 |

ISA는 순이익 기준 비과세 한도(일반형 200만원 / 서민형·농어민형 400만원)와 초과분 분리과세를 적용합니다. 계좌 밖에서 이미 매매차익이 비과세인 국내주식형은 ISA로 얻을 절세분이 분배금에 한정되고, 계좌 밖에서 전액 과세되는 나머지 유형은 절세 실익이 큽니다.

### 신설할 필드

| 필드 | 값 | 판정키 |
|---|---|---|
| `isa_eligible` | 가능 / 불가 | 국내 증권시장 상장 여부 (현재 전건 가능 — 유지) |
| `isa_tax_type` | 국내주식형 / 기타 | `kofia_fund_type = 주식형` **and** `asset_class = 주식-국내` → 국내주식형 |
| `isa_tax_benefit` | 높음 / 낮음 | `isa_tax_type = 기타` → 높음, `국내주식형` → 낮음 |
| `isa_education_required` | Y / N | 레버리지·인버스 (사전교육 및 기본예탁금) — 현행 유지 |

`isa_tax_type` 판정은 퇴직연금 축과 달리 **개별 투자설명서가 불필요**합니다. 이미 보유한 `kofia_fund_type` + `asset_class`만으로 1,167건 전수 판정이 가능합니다. 즉 **ISA 축은 오늘 안에 100% 채울 수 있습니다.**

### 컴플라이언스 문구 규칙

콘텐츠·화면 노출 시 다음을 지킵니다.

- "ISA에 담으면 유리합니다" (X) → "이 유형은 계좌 밖에서 매매차익이 과세되므로, ISA의 분리과세 대상이 됩니다" (O)
- 실제 절세액은 가입자의 소득 구간, 계좌 유형(일반/서민형), 납입한도, 의무보유기간에 따라 달라진다는 점을 함께 표기합니다.
- 세법은 개정 가능하므로 판정 기준일(`as_of`)을 화면에 노출합니다.

### Step 1 — 선행 차단 작업 (419건 착수 전 반드시 완료)

## 10. 완료 기준 — 지표를 %가 아니라 등급별로 보고하십시오

`verified 64.1%` 같은 단일 백분율은 F-1을 은폐합니다. 다음 형식으로 보고합니다.

```json
{
  "as_of": "YYYY-MM-DD",
  "total": 1167,
  "by_evidence_grade": {
    "E0_법령직접": 0, "E1_투자설명서본문": 0, "E2_정정신고서": 0,
    "E3_협회단순유형": 0, "E4_판매사유니버스": 0,
    "UNVERIFIED": 0
  },
  "promotable_verified": 0,
  "s5_evidence_sufficiency_violations": 0,
  "isa_tax_type_coverage_pct": 0
}
```

- `promotable_verified` = E0 + E1 + E2 + (E3∩E4). 이것만 `pension_verified = Y`입니다.
- `s5_evidence_sufficiency_violations`가 0이 아니면 **어떤 승격도 보고하지 마십시오.**
