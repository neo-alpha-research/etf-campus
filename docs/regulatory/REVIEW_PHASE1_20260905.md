## 2. P1-1 — 제4-54조를 확보했다고 E0가 되지 않습니다 (치명)

### 확보한 조문의 실제 내용

```
제4-54조(위험평가액 산정방법)
① … 위험평가액은 장내파생상품 또는 장외파생상품의 거래에 따른 명목계약금액으로 하며,
   그 명목계약금액은 다음 각 호의 방법으로 산정하되…
   1. … 기초자산의 가격에 거래량(계약수)과 승수를 곱하여 산정한다.

② 제1항에 불구하고 집합투자업자는 다음 각 호의 어느 하나에 해당하는 방법으로
   명목계약금액을 산정할 수 있다.
   1. … 위험회피회계의 적용대상이 되는 거래 : 명목계약금액 산정대상에서 제외하는 방법
   2. … 금융감독원장이 지정한 거래 : 조정값을 반영하여 위험평가액을 감액하는 방법
   3. 기초자산이 동일하고 가격의 변화방향이 반대인 파생상품 거래 : … 상계한 후
      잔여 명목계약금액을 위험평가액으로 산정하는 방법
```

이 조문은 **계산 방법**을 정합니다. **어떤 상품의 위험평가액이 얼마인지는 말하지 않습니다.**

그런데 원장의 33건에 붙은 note는 전부 동일합니다.

```
장내선물 명목계약금액 기준 위험평가액 40% 초과 편입불가
```

**"40% 초과"라는 결론은 조문에서 나오지 않습니다.** 그 결론을 얻으려면 각 ETF의 실제 계약수·승수·기초자산 가격이 필요하고, 제2항 제1~3호의 제외·감액·상계가 적용되는지도 종목마다 다릅니다.

### 이것은 배치1의 재현이며, 한 층 위에서 일어났습니다

| | 배치1 | Phase 1 선물군 |
|---|---|---|
| 파일 실존 | ✓ | ✓ |
| 해시 일치 | ✓ | ✓ |
| **인용 문구가 파일에 실재** | ✗ (그래서 걸림) | **✓** |
| **그 문구가 그 결론을 함의** | — | **✗** |

S5는 "문구가 파일에 있는가"를 검사합니다. "그 문구가 그 결론을 뒷받침하는가"는 검사하지 않습니다. **S5를 통과했지만 논증은 성립하지 않습니다.**

`s5_evidence_sufficiency_violations: 0`은 이번에는 사실입니다. 다만 그 지표가 보증하는 범위가 좁다는 것이 드러났습니다.

### 지시

- 선물 33건의 `evidence_grade`를 **E0 → `RULE`(규칙기반추론)** 로 변경하고 `pension_verified = N`으로 되돌리십시오
- `promotable_verified` 959 → **926**
- 제4-54조는 `statute_registry`에 그대로 두십시오. 조문 자체는 필요합니다. 다만 이 조문 단독으로 종목을 판정할 수 없습니다

## 3. P1-2 — 국채선물 9건은 지금 상태로 두면 위험합니다

선물 33건을 KOFIA 유형별로 나눴습니다.

| 유형 | 건수 | 추론의 타당성 |
|---|---|---|
| 특별자산파생 (원자재·통화 선물) | 16 | **높음** — 실무에서도 퇴직연금 불가로 통용 |
| 주식파생형 (해외지수 선물) | 4 | 보통 |
| 미매칭 | 4 | 미확인 |
| **채권파생형 (국채선물)** | **9** | **낮음 — 검증 필요** |

국채선물 9건 전건입니다.

```
305080 TIGER 미국채10년선물        304660 KODEX 미국30년국채울트라선물(H)
308620 KODEX 미국10년국채선물      298340 PLUS 국채선물3년
152380 KODEX 국채선물10년         289670 PLUS 국채선물10년
432600 RISE 국채선물3년           295000 RISE 국채선물10년
267440 RISE 미국장기국채선물(H)
```

### 왜 위험한가

이들은 **채권 익스포저를 만드는 상품**이고 협회 분류도 `채권파생형`입니다. 감독규정 제11조 제1항 제4호는 채권형을 안전자산으로 명시합니다. 채권 노출을 선물로 구현했다는 이유만으로 **편입 불가**로 판정하면, 실무 분류와 정면으로 어긋날 가능성이 큽니다.

만약 판매사 화면에서 이들이 편입 가능으로 나온다면, 우리 서비스는 **투자자가 담을 수 있는 상품을 담을 수 없다고 표시**하게 됩니다. 안전자산을 위험자산으로 표시하는 것만큼이나 실질적인 오정보입니다.

### 지시

33건을 균질하게 다루지 마십시오. **국채선물 9건과 원자재·통화 16건을 분리**하고, 각 그룹에서 **표본 2~3건씩을 판매사 퇴직연금 화면 또는 발행사 공시와 대조**하십시오.

- 표본이 "불가"로 확인되면 그 그룹의 추론이 검증된 것이므로 등급 `RULE`로 유지하되 신뢰도를 올립니다
- 표본이 "편입 가능"으로 나오면 **그 그룹 전체를 즉시 되돌리십시오**

추론을 표본으로 검증하는 것이 이 단계에서 가장 비용 대비 효과가 큽니다. 33건 전부를 개별 확인할 필요는 없습니다.

## 4. P1-3·P1-4·P1-5 — TDF 13건

### P1-3. 시행세칙 파일의 출처가 확인되지 않습니다

```
# 퇴직연금감독규정시행세칙 (금융감독원세칙 제9999호, 시행일자: 20260401)
```

**제9999호**는 실재하는 세칙 번호가 아닙니다. 자리표시자입니다.

그리고 신규 3개 파일만 `.txt` 단독입니다. 기존 법령은 전부 `.html` + `.txt` 쌍으로 저장되어 있습니다.

```
퇴직연금감독규정_20260905.html      231,608  ← law.go.kr 원본
퇴직연금감독규정_20260905.txt        54,673
퇴직연금감독규정시행세칙_20260905.txt   6,874  ← 원본 없음
금융투자업규정_제4-54조_20260905.txt   7,316  ← 원본 없음
자본시장법시행령_제240조_20260905.txt   3,517  ← 원본 없음
```

내용 자체는 상당히 정교하고 실제 조문일 가능성이 높습니다. **그러나 그것이 검증은 아닙니다.** 우리가 배치1에서 배운 것이 정확히 이것입니다 — 그럴듯함은 증거가 아닙니다.

**지시**: 세 파일 모두 원 출처(law.go.kr HTML 또는 금융감독원 공식 문서)를 함께 저장하고, 세칙 번호를 실제 번호로 교체하십시오. 확보 불가하면 `statute_registry`에 `출처미확인` 플래그를 다십시오.

### P1-4. 보고한 요건이 확보한 파일과 다릅니다

**보고서:**
> 적격 TDF 3대 요건(은퇴시점 5년 이상, **초기 주식 80% 이내 → 40% 이하 글라이드패스**, 부적격채권 20% 이내)

**확보한 파일의 실제 제5조의2:**
```
3. … 현금성자산 및 채무증권 … 의 비중을 투자목표시점 이전에는 자산총액의 100분의 20 이상으로 하고,
   투자목표시점 이후에는 자산총액의 100분의 60 이상으로 할 것
4. 투자적격등급 이외의 채무증권의 투자한도를 자산총액의 100분의 20 이내로 하고,
   채무증권 투자액의 100분의 50 이내로 할 것
5. 해외 특정 국가에 대한 주식 및 채권의 투자한도는
   주식의 경우 주식투자액의 100분의 80 이내, 채권의 경우 채권투자액의 100분의 80 이내로 할 것
```

조문은 **주식 상한**이 아니라 **현금성자산·채무증권 하한**(20% 이상 / 60% 이상)으로 규정합니다. 그리고 요건은 3개가 아니라 **5개**이며, 제5호(해외 특정국 80% 이내)는 아예 보고에 없습니다.

논리적으로 "채무증권 60% 이상"과 "주식 40% 이하"는 대략 등가일 수 있으나, **조문 문언이 다르면 판정 로직도 달라집니다.** 예컨대 현금성자산이 포함되므로 주식 40% 초과여도 요건을 충족할 수 있습니다.

**자기가 확보한 파일을 읽지 않고 외부 요약(NotebookLM)을 그대로 옮긴 것입니다.** 이것이 P1-3보다 심각합니다. 파일이 진짜라 해도 그것을 근거로 쓰지 않았기 때문입니다.

### P1-5. 종목별 대조 증거가 없습니다

13건의 `evidence_quote`가 **전건 동일한 조문 문구**입니다.

```
제5조의2(적격 집합투자증권 인정기준) 규정 제11조제1항제9호의 감독원장이 정한 기준을…
```

이것은 "그런 조문이 있다"는 증거이지 "이 상품이 그 요건을 충족한다"는 증거가 아닙니다. 보고서의 "**3대 요건 대조 완료**"는 사실이 아닙니다.

5개 요건 중 명칭만으로 확인되는 것은 제2호(목표시점 5년 이후 + 명칭 기재)뿐입니다. 제1호(글라이드패스), 제3호(현금성자산·채무증권 하한), 제4호(투자부적격 20%), 제5호(해외 특정국 80%)는 **각 상품의 집합투자규약 또는 투자설명서**를 봐야 합니다.

레드라인 9번 — "상품명의 '적격'·'레버리지' 같은 문자열만으로 승격 금지" — 을 그대로 위반했습니다.

**지시**: TDF 13건을 `pension_verified = N`으로 되돌리십시오. `promotable_verified` **926 → 913**.

다만 이 트랙은 되살릴 방법이 명확합니다. 발행사 상품 페이지에 글라이드패스와 자산배분 계획이 공시되어 있으므로, **종목별 `evidence_quote`에 각 상품의 실제 배분 수치를 넣으면** E1B로 정당하게 승격됩니다. 조문은 이미 확보했으니 절반은 끝난 셈입니다.

## 5. P1-6 — 레버리지·인버스 103건은 명칭 매칭입니다

실측 결과입니다.

- `data/regulatory/sources/`에 **KRX 추적배수 파일이 없습니다**
- 103건의 `evidence_ref`가 전부 `퇴직연금감독규정_20260905.txt`
- 103건 중 **명칭에 `레버리지`·`인버스`·`2X`가 없는 건이 0건**

즉 명칭 문자열로 필터링한 뒤 조문을 근거로 붙였습니다. P2 지시("KRX 추적배수 출처 확보, 판정키는 추적배수이고 명칭은 보조지표")를 수행하지 않았습니다.

### 다만 이 건은 실질 위험이 낮습니다

레버리지·인버스는 명칭 규칙이 매우 강건합니다. 오탐(편입 가능한데 불가로 판정) 위험은 사실상 없습니다.

문제는 **누락**입니다. 명칭에 배율 표기가 없는 배율 상품이 있으면 잡히지 않습니다. 그리고 **등급이 정직하지 않습니다** — 이것은 법령 문언만으로 결정된 E0가 아니라 명칭 규칙에 법령을 적용한 것입니다.

### 지시

두 가지 중 하나를 선택하십시오.

1. **KRX 추적배수를 확보**해 `evidence_ref`를 그 데이터로 교체하고 E0를 유지 (권장)
2. 확보가 어려우면 **등급을 `RULE_NAME`(명칭규칙)** 으로 재명명하고 `pension_verified`는 유지하되 `pension_confidence = 보통`

## 9. S5의 다음 단계 — 논증 검사

이번에 드러난 것은 S5의 구조적 한계입니다.

```
S5 (현재): evidence_ref 파일에 evidence_quote 문구가 실재하는가          → 검사함
S6 (필요): 그 문구가 note의 결론을 함의하는가                            → 검사 안 함
```

S6를 완전 자동화할 수는 없습니다. 다만 최소한의 게이트는 만들 수 있습니다.

```
S6-a: evidence_quote가 종목별로 동일하면(같은 조문 문구를 N건에 반복 사용)
      그 승격은 '조문 인용'이지 '종목 대조'가 아니므로 evidence_grade를 E0로 둘 수 없다.
      → TDF 13건, 선물 33건이 이 검사에 걸립니다.

S6-b: E0는 evidence_ref가 법령 파일이면서, note의 결론이 그 조문의
      문언만으로 도출되는 경우로 한정한다. 결론에 수치 판정
      ('40% 초과' 등)이 포함되면 E0 부여 금지.
      → 선물 33건이 걸립니다.
```

**S6-a는 이번 두 오류를 모두 잡습니다.** 구현 비용도 낮습니다. Phase 2 착수 전에 넣으십시오.
