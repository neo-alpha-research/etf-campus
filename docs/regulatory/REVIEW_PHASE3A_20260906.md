## 2. 보고서의 유일한 부정확 — SHA-256

| 파일 | 보고서 기재 | 실제 |
|---|---|---|
| xlsx | `74cb03…` | `7e1429bd…` |
| html | `62bb01…` | `229c93f6…` |
| json | `a12a4c…` | `930dbbaf…` |

`evidence_manifest.json`에는 **실제 값이 정확히 들어 있고** E5 검증도 정상입니다. 즉 파일과 시스템은 문제없고 **보고서 본문의 해시만 지어냈습니다.**

기능적 영향은 없습니다. 다만 이 프로젝트의 맥락에서는 짚습니다 — **검증할 수 없는 숫자를 보고서에 쓰지 마십시오.** manifest에서 읽어 붙이면 됩니다.

### 3자 합치는 과잉 설계입니다

| 축 | 성격 |
|---|---|
| 판매사(한국투자증권) | 퇴직연금사업자가 **실제 매매 시스템에 적용하는 분류**. 감독규정 제14조상 위반 운용지시를 거절할 의무를 지는 주체 |
| 규제 엔진 | 우리가 조문에서 도출한 판정 |
| 발행사(TIGER/KODEX) | 운용사의 자체 안내. 판매사와 성격이 겹침 |

판매사와 발행사는 **독립적인 두 증거가 아니라 같은 층위의 실무 판정**입니다. 반면 판매사와 규제 엔진은 층위가 다릅니다 — 하나는 실무, 하나는 조문. **이 둘이 일치하면 그것이 진짜 교차검증입니다.**

발행사는 있으면 신뢰도를 높이는 보강 자료이지 필수 조건이 아닙니다.

**지시: 승격 기준을 `판매사 + 규제 엔진 2자 일치`로 완화하고, 발행사 확인 여부는 `evidence_tier`(2way / 3way)로 구분 기록하십시오.**

## 8. Phase 3B 지시서

### Step 1 — 승격 기준 완화 (91건)

`판매사 + 규제 엔진 2자 일치`로 기준 변경. `evidence_tier` 컬럼 신설(`2way` / `3way`).

- `evidence_grade = E4`
- `evidence_quote`: 엑셀에서 실제로 읽은 행 값 — 예 `한국투자증권 퇴직연금 ETF 상품 현황(2026-08-31 기준) / KODEX 200 / 069500 / 삼성 / 퇴직연금 투자한도 0.7`
- `source_url`: 공지 URL, `evidence_ref`: xlsx 경로
- `expires_at`: **2026-11-30** (엑셀 기준일 2026-08-31 + 90일)

**→ 1,019 + 91 = 1,110건 (95.1%)**

### Step 2 — 엔진 수정 후 재판정 (12건)

§7의 처방 적용. 수정 규칙 3가지를 `pension_regulatory_engine.py`에 반영하십시오.

```
R-a. KOFIA 유형이 특별자산·특별자산파생이면 제11조 제1항 제5호를 적용하지 않는다
     (별지 제15호: 특별자산집합투자기구는 재산의 50% 이상이 증권·부동산 외 자산)
R-b. 외화 금리(미국달러 SOFR 등) 기초 상품은 안전자산으로 분류하지 않는다
R-c. 상품명에 '선물'이 있어도 '(합성)' 표기가 있으면 장외파생 단서(제9조1항2호마목)
     적용 여부를 먼저 판정한다
```

수정 후 한투와 일치하면 승격. **→ 1,110 + 12 = 1,122건 (96.1%)**

### Step 3 — 선물 25건 정식 승격

엑셀 2행 `★매매불가: 레버리지/인버스/파생형/해외상장ETF` + 25건 전건 미수록을 근거로 `불가` 확정.

- `evidence_grade = E4`, `evidence_tier = 2way`
- `evidence_quote`에 **엑셀 2행 원문**과 "해당 종목코드 미수록" 사실을 함께 기재
- 부재(不在)를 근거로 쓰는 것이므로 **엑셀 전체 종목코드 집합을 별도 파일로 보존**하고 그 파일을 `evidence_ref`에 병기하십시오

**→ 1,122 + 25 = 1,147건 (98.3%)**

### Step 4 — 잔여 20건

한투 엑셀 미수록 43건 중 선물 25건을 뺀 나머지 + 불일치 잔여 2건입니다. 대부분 신규 상장분으로 보입니다.

- **2차 판매사 1곳 확보**가 최선입니다. 미래에셋증권·삼성증권·KB증권의 동종 공지를 찾으십시오. 한국투자증권이 공개 공지로 올린다면 다른 곳도 가능성이 있습니다
- 확보되지 않으면 **미검증으로 두십시오.** 여기서 무리하지 마십시오

### Step 5 — 갱신 파이프라인

엑셀이 **월간 갱신**입니다. 이번 작업을 일회성으로 끝내지 마십시오.

```
매월: 공지 확인 → 엑셀 다운로드 → SHA-256 등록 → 전수 재대조
     → 한도 변경 종목 리포트 → expires_at 갱신
```

약관 개정으로 한도가 바뀝니다(284430 사례). 갱신 없이 두면 3개월 뒤 잘못된 정보가 됩니다.
