## 3. 논리 일관성 문제 — "미수록 = 불가"의 적용 범위

Step 3은 한투 미수록을 근거로 27건을 `불가` 확정했습니다. 그런데 **미수록인데 승격하지 않은 종목이 16건 남아 있습니다.**

| 미수록 잔여 | 건수 | 우리 판정 |
|---|---|---|
| 롱숏선물·유럽탄소배출권(H) | 4 | 불가 (미승격) |
| 커버드콜·해외주식 | 5 | 70% |
| 부동산·리츠 | 3 | 70% |
| 신규상장 | 4 | 70%/100% |

**커버드콜 5건과 부동산 3건을 승격하지 않은 것은 올바른 판단입니다.** 다른 커버드콜과 리츠 ETF는 엑셀에 정상 수록되어 0.7을 받고 있으므로, 이들의 미수록은 배제 사유가 아니라 **한투 상품 라인업 미포함**일 뿐입니다.

**그러나 그 판단 기준이 명문화되어 있지 않고, 롱숏선물 2건·유럽탄소배출권(H) 2건은 27건과 같은 논리인데도 빠졌습니다.**

### 규칙을 명문화하십시오

```
R-d. 한투 엑셀 미수록은 다음 조건에서만 '불가'의 증거가 된다.
     엑셀 2행이 명시한 배제 4사유 — 레버리지 / 인버스 / 파생형 / 해외상장 —
     중 하나에 해당함이 KOFIA 펀드유형 또는 상품 구조로 확인될 것.

     그 외의 미수록은 '판매사 취급 여부'일 뿐 규제 판정의 근거가 아니다.
     이 경우 판정은 규제 엔진 단독 결과를 유지하고 미검증으로 둔다.
```

이 규칙을 적용하면 **롱숏선물 2건(360140·360150)과 유럽탄소배출권선물(H) 2건(400570·400580)은 파생형에 해당하므로 즉시 승격 가능**합니다. 27건과 동일한 증거 구조를 쓰면 됩니다.


**R-a 규칙(특별자산 → 안전자산 배제)이 357870·477080에서는 역효과를 냈습니다.** 이 두 종목은 R-a 적용 전에는 한투와 일치했는데, R-a 적용 후 어긋났습니다.

그리고 453010·458210은 협회 유형이 혼합채권파생형(증권형)인데 한투가 0.7을 줍니다. 즉 **협회 유형과 판매사 판정이 이 4건에서 서로 어긋납니다.**

원인 후보는 두 가지입니다.

1. **협회 펀드유형 표기가 부정확** — 실제 약관은 다를 수 있음
2. **한투 분류에 별도 기준** — 환헤지 여부, 스왑 담보 구조 등

**해법은 원본 약관입니다.** 이 4건만 KOFIA DIS에서 집합투자규약을 열어 (a) 집합투자기구 종류(증권형/특별자산), (b) 약관상 주식 투자한도를 직접 확인하십시오. 4건이므로 비용이 크지 않고, 확인되면 `E1`(투자설명서 본문) 최상위 등급으로 승격됩니다.

## 5. Phase 3C 지시서

### Step 1 — A그룹 4건 즉시 승격

R-d 규칙을 `pension_regulatory_engine.py`에 명문화하고, 27건과 동일한 증거 구조(xlsx + ticker universe + 종목별 인용문)로 승격.

**→ 1,151건 (98.6%)**

### Step 2 — C그룹 4건 약관 직접 확인

```
357870 TIGER CD금리투자KIS(합성)
477080 RISE CD금리액티브(합성)
453010 PLUS KOFR금리
458210 KIWOOM CD금리액티브(합성)
```

KOFIA DIS(`dis.kofia.or.kr`)에서 각 펀드의 **집합투자규약·투자설명서**를 열어 다음 두 가지를 원문으로 확인하십시오.

- 집합투자기구 종류: 증권집합투자기구인가 특별자산집합투자기구인가
- 약관상 주식 투자한도

확인된 사실이 협회 유형과 다르면 **협회 유형이 아니라 약관을 따르십시오.** `evidence_grade = E1`, `evidence_quote`에 약관 원문 인용.

R-a 규칙도 이 결과에 맞춰 정밀화해야 합니다. 현재는 "협회 유형이 특별자산파생이면 안전자산 배제"인데, 협회 유형이 부정확할 수 있으므로 **약관 확인분은 예외로 두는 분기**가 필요합니다.

**→ 1,155건 (99.0%)**

### Step 3 — 2차 판매사 확보 (D·E 그룹 8건)

한국투자증권이 공개 공지로 올린다면 다른 곳도 가능합니다. 다음을 순서대로 확인하십시오.

```
미래에셋증권   퇴직연금/연금 공지사항
삼성증권       퇴직연금 안내·공지
KB증권         퇴직연금 운용상품 / 자산배분ETF 조회
NH투자증권     퇴직연금 상품 공시
신한투자증권    퇴직연금 매매가능 상품
```

검색어: `퇴직연금 매매가능 ETF 리스트`, `퇴직연금 ETF 상품 현황`, `DC IRP ETF 목록`

1곳만 더 확보되면 D·E 8건이 해결되고, 동시에 **기존 1,147건 전체가 2개사 교차검증(`3way` 상당)으로 격상**됩니다. 이것이 8건 승격보다 큰 소득입니다.

확보 실패 시 D·E 8건은 미검증으로 두십시오. 조문만으로는 판정할 수 없습니다.

### Step 4 — B그룹 4건 및 월간 갱신 체계

```
매월 초:
  1. 한국투자증권 공지에서 신규 엑셀 다운로드
  2. SHA-256 등록 + ticker universe 파일 재생성
  3. 전수 재대조 → 한도 변경 종목 리포트
  4. 신규상장분 자동 판정 → 미검증 큐 해소
  5. expires_at 일괄 갱신 (기준일 + 90일)
```

신규상장 4건은 9월말 엑셀에 들어올 가능성이 높습니다. **기다리는 것이 정답입니다.**

## 6. 100%에 대해 — 목표 설정을 바꾸십시오

Step 1~4를 마치면 **1,155~1,163건(99.0~99.7%)** 에 도달합니다. 나머지는 2차 출처 확보 여부에 달렸습니다.

그런데 더 중요한 것이 있습니다.

**100%는 순간값이지 정상상태가 아닙니다.** ETF는 매월 신규 상장되고, 한투 엑셀은 월말 기준이며, 협회 공시는 그보다 늦습니다. 오늘 100%를 찍어도 다음 주 신규 상장 3건이 들어오면 99.7%가 됩니다.

그러니 목표를 이렇게 바꾸십시오.

```
[X] 검증률 100% 달성
[O] 매월 엑셀 갱신 후 미검증 잔여 5건 이하 유지
    + 잔여 종목은 화면에 "확인 중" 표시
    + 잔여 사유를 종목별로 설명 가능한 상태 유지
```

지금 잔여 20건은 **전부 사유가 명확하고 종목별로 설명 가능합니다.** 그것이 100%라는 숫자보다 나은 상태입니다. Phase 2D에서 배운 것이 바로 이것입니다.
