## 2. `evidence_tier` 재계산이 이중 지표를 무너뜨렸습니다

### 실측한 tier × grade 교차표

```
482  tier=3way       grade=E3
331  tier=statutory  grade=E3        ← E3 813건이 둘로 쪼개짐
144  tier=3way       grade=E4
103  tier=statutory  grade=RULE_NAME
 86  tier=2way       grade=E4
  7  tier=statutory  grade=E1B    /   6  tier=3way  grade=E1B
  2  tier=statutory  grade=E1     /   1  tier=3way  grade=E2
```

`statutory`가 932 → **443건**으로 줄었습니다. 보고서는 이를 성과로 기재했지만, 지표 관점에서는 **법령 근거 확보율이 반토막 난 것처럼 보입니다.**

### 원인 — 한 컬럼에 두 축을 섞었습니다

| 축 | 의미 | 값 |
|---|---|---|
| 증거 **종류** | 무엇으로 판정했는가 | E1 / E1B / E2 / E3 / E4 / RULE_NAME |
| 출처 **개수** | 몇 곳이 확인했는가 | 1way / 2way / 3way |

`evidence_tier`에 `statutory`(종류)와 `2way/3way`(개수)가 함께 들어 있어, 출처 수를 재계산하면 종류 정보가 덮어써집니다.

**E3 종목이 발행사·판매사 확인을 추가로 받았다고 해서 법령 근거가 사라지는 것이 아닙니다.** 오히려 근거가 강해진 것인데, 지표는 반대로 움직였습니다.

### 지시 — 두 컬럼으로 분리하십시오

```
evidence_grade  : 증거 종류 (기존 유지)
evidence_tier   : 출처 개수만. 값을 1way / 2way / 3way 로 한정하고 statutory 제거
```

그러면 이중 지표가 이렇게 정확히 산출됩니다.

```
법령 근거 확보율 = E1(2) + E1B(13) + E2(1) + E3(813)  =   829건 (71.0%)
실무 확인율      = 전체 검증                            = 1,162건 (99.6%)
교차검증 강도    = 3way 633 / 2way 86 / 1way 443
```

`RULE_NAME` 103건은 명칭 규칙 기반이므로 법령 근거에서 제외하는 편이 정확합니다. 판정키가 조문이 아니라 상품명이기 때문입니다.

## 4. 잔여 5건 처리 — 100% 경로

### 4-1. 0198A0은 승격 가능합니다

R-d 규칙을 그대로 적용하면 결론이 나옵니다.

```
R-d. 한투 미수록은 엑셀 2행의 배제 4사유(레버리지/인버스/파생형/해외상장)에
     해당할 때만 불가의 증거다. 그 외 미수록은 판매사 취급 여부일 뿐 판정 근거가 아니다.
```

커버드콜은 배제 사유가 아닙니다. 다른 커버드콜이 엑셀에 정상 수록되어 0.7을 받고 있습니다. 따라서 **한투 미수록은 반증이 아니며, 유효한 출처는 키움 공시 하나입니다.**

```
290080 · 489030 : 발행사 "퇴직연금 없음" + 한투 미수록 → 두 출처 일치 → 불가
0198A0          : 발행사 "퇴직연금 가능" + 한투 미수록(판정 근거 아님) → 발행사만 유효 → 70%
```

논리적으로 대칭이며 일관됩니다. **키움 공시(`pensionFlags: ['개인연금','퇴직연금']`) + 규제 엔진(70%) = 2way로 승격**하고, `note`에 "한국투자증권 미취급(라인업 사유)"을 기재하십시오.

**→ 1,163건 (99.66%), 잔여 4건**
