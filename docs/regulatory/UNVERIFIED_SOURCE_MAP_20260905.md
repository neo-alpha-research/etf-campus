# 미검증 ETF 확인 경로 지도 (Source Map)

- 작성일: 2026-09-05
- 대상: Phase 2D 회수 후 미검증 상태로 돌아갈 **237건**
- 검증 방식: NotebookLM이 제시한 3대 경로를 **실제로 열어보고** 유효성 확인
- 원칙: 확인한 것과 확인하지 못한 것을 구분해 표기합니다

## 0. 요약 — NotebookLM 3대 경로의 실제 유효성

| NotebookLM 제시 경로 | 실측 결과 | 판정 |
|---|---|---|
| ① 신탁약관·투자설명서 (운용사/DART/KIND) | 존재. 단 OpenDART API로는 본문 불가(기확인) | **유효, 수집 방법 제약** |
| ② 금융투자협회·은행연합회 비교공시 | **`pension.kofia.or.kr` 호스트 자체가 없음(DNS 실패).** 금감원 통합연금포털 비교공시는 원리금보장상품·사업자 수익률 중심 | **부분 오류** |
| ③ 퇴직연금사업자 시스템 화면 | 계좌 로그인 필요가 원칙. **그러나 일부 증권사가 월간 공개 공지로 리스트를 게시** | **유효, 단 경로 수정 필요** |

**가장 중요한 발견**: 한국투자증권이 「**퇴직연금 매매가능 ETF/상장REITs 리스트**」를 매월 공개 공지로 게시하고 있습니다. 로그인 없이 접근 가능한 판매사 유니버스가 실재합니다. 이것 하나로 237건 대부분의 **결론값**을 얻을 수 있습니다.

## 2. 경로 ③ — 판매사 공개 유니버스 (최우선, 결론값 확보)

### 2-1. 한국투자증권 퇴직연금 공지 ★ 최유력

```
https://securities.koreainvestment.com/pension/nwEtcinfo/Notice.jsp
공지 제목 예: 「퇴직연금 매매가능 ETF/상장REITs 리스트_202512」
```

- 검색으로 **공지 존재를 확인**했습니다 (제목·URL 확인)
- 다만 `robots.txt` 차단으로 **내용은 직접 확인하지 못했습니다.** 브라우저로 직접 열어 컬럼 구성을 먼저 보십시오
- 확인할 것: 종목코드 유무, **안전자산/위험자산 구분 컬럼 유무**, 첨부 형식(엑셀/PDF), 기준일자
- 월간 갱신으로 보이므로 **매월 스냅샷 아카이빙**이 가능합니다

**이 공지에 한도 구분 컬럼이 있으면 237건의 결론값 대부분이 한 번에 확보됩니다.** 가장 먼저 확인하십시오.

### 2-2. KB증권

```
퇴직연금 유의사항(위험자산 투자한도): https://www.kbsec.com/go.able?linkcd=s080400070100
자산배분ETF 조회:                    https://www.kbsec.com/go.able?linkcd=m08040007
```

직접 열어 확인한 결과, 유의사항 페이지는 **자산군 수준 안내만** 있고 종목별 목록은 없습니다. 별도 조회 화면으로 연결됩니다.

### 2-3. 미래에셋증권

Antigravity가 237건 전건의 근거로 인용한 URL은 **시스템 점검 공지 페이지**였습니다(직접 확인). 미래에셋증권의 실제 퇴직연금 상품 공시 경로를 따로 찾아야 합니다.

### 판매사 경로의 증거 등급

판매사 표기는 **법령을 적용한 결론**이지 법령 사실이 아닙니다.

- 등급 `E4`, **단독 승격 불가**
- **2개사 이상 일치**할 때만 결론값으로 채택
- 원본 스냅샷(HTML/PDF/엑셀) 디스크 보존 + SHA-256 필수
- `expires_at` 90일 — 약관 개정 시 바뀝니다

## 3. 경로 ① — 약관·투자설명서 (법령 사실 확보)

### 3-1. 금융투자협회 전자공시 (KOFIA DIS)

```
https://dis.kofia.or.kr
```

펀드별 상세에서 **투자설명서·집합투자규약 원문**으로 연결됩니다. 우리는 이미 이 시스템의 보수공시 XML(30MB)을 보유 중이며, 협회 표준코드로 개별 펀드를 특정할 수 있습니다.

**A그룹(커버드콜 108건)의 파생 위험평가액**과 **D그룹(재간접 22건)의 사모 편입 여부**는 여기서만 확인됩니다.

### 3-2. DART

```
전자공시: https://dart.fss.or.kr
```

- **OpenDART API(`document.xml`)로는 투자설명서 본문을 얻을 수 없습니다.** 실호출로 확인 완료 — 표지만 반환되고 `[ 본 문 ]` 이후가 비어 있습니다
- **정정신고서만** 예외적으로 유효합니다. 정정 대비표가 본문에 실리기 때문입니다 (284430 사례)
- 본문이 필요하면 **DART 웹 뷰어**(`dsaf001/main.do?rcpNo=…`)를 브라우저로 열어야 합니다

**B그룹 경계값 9건**(약관 주식한도가 `50% 미만`인지 `50% 이하`인지)은 정정신고서 스윕으로 확인 가능합니다.

### 3-3. 운용사 홈페이지

개별 ETF 상세 페이지를 직접 열어 확인했습니다.

| 운용사 | 개별 종목 페이지의 퇴직연금 한도 표기 |
|---|---|
| TIGER (미래에셋) | **없음** — NAV·수익률·보수·기초지수·AP/LP·듀레이션·분배금만 |
| KODEX (삼성) | 개별 페이지에서 확인 불가 (JS 렌더링) |

**개별 상품 페이지에는 퇴직연금 한도가 없습니다.** 대신 연금 전용 페이지가 따로 있습니다 (§4).

투자설명서·집합투자규약 PDF는 각 운용사 상품 페이지에서 내려받을 수 있습니다. 이것이 **약관 사실**의 1차 출처입니다.

## 4. 운용사 연금 전용 페이지 (신규 발견)

```
TIGER: https://investments.miraeasset.com/tigeretf/ko/pension/investment/list.do
KODEX: https://www.samsungfund.com/etf/product/pensionlist.do
```

TIGER 페이지를 열어 확인한 결과, **개인연금 / 퇴직연금 DC·IRP / ISA 중개형 3개 계좌의 투자 제한을 비교하는 표**와 **금지 유형 안내표**가 있습니다. 우리가 만들려는 분류축과 정확히 같은 구조입니다.

다만 **종목별 리스트는 JavaScript로 렌더링**되어 정적 조회로는 읽히지 않았습니다. 브라우저(또는 헤드리스 브라우저)로 열어야 종목 데이터가 보입니다.

**이 두 페이지가 발행사 공식 공시(E1B)의 실제 소재입니다.** Phase 2D에서 하려던 일의 올바른 출발점입니다.

## 5. 경로 ② — 비교공시 (NotebookLM 서술에 오류가 있습니다)

### 확인 결과

| 대상 | 결과 |
|---|---|
| `pension.kofia.or.kr` | **호스트가 존재하지 않습니다** (DNS 조회 실패) |
| 금감원 통합연금포털 퇴직연금 비교공시 | 공시 대상이 **원리금보장상품 목록**과 **사업자별 수익률·수수료**. ETF 종목별 안전자산/위험자산 분류는 대상이 아님 |
| 은행연합회 소비자포털 | 은행 퇴직연금 **수익률 비교** 중심 |

```
통합연금포털:       https://www.fss.or.kr/fss/lifeplan/lifeplanIndex/index.do?menuNo=201101
원리금보장상품 목록:  https://law.fss.or.kr/fss/lifeplan/rtrmGoods/list.do?menuNo=200970
사업자 수익률:      https://fss.or.kr/fss/lifeplan/rtrmCmpr/list.do?menuNo=200965
은행연합회:         https://portal.kfb.or.kr/compare/retirement.php
```

**NotebookLM의 "협회 비교공시가 ETF 종목별 분류를 공시한다"는 서술은 확인되지 않습니다.** 감독규정 제23조와 시행세칙 제7조의 비교공시 의무는 원리금보장상품과 사업자 지표 중심입니다.

### 다만 하나 남은 단서

사업자별 「**원리금 비보장상품**」 공시는 별도로 존재합니다. 예: KB퇴직연금 `okbfex.kbstar.com/quics?page=C025544` (robots 차단으로 내용 미확인).

원리금 비보장상품에 ETF가 포함되고 한도 구분이 표기된다면 §2와 같은 경로가 됩니다. **확인해 볼 가치는 있으나 기대치는 낮게 두십시오.**

## 7. 착수 순서

**1단계 — 한국투자증권 공지를 브라우저로 열어 컬럼을 확인하십시오.** 안전자산/위험자산 구분이 있으면 237건 대부분의 결론값이 확보됩니다. 여기서 모든 것이 갈립니다.

**2단계 — 운용사 연금 페이지 2곳**(TIGER·KODEX)을 헤드리스 브라우저로 수집하십시오. 판매사와 교차 대조할 두 번째 출처가 됩니다.

**3단계 — 두 출처가 일치하는 종목만** `E4`로 결론값을 기록하십시오. 불일치 종목은 미검증으로 남기고 목록을 보고하십시오.

**4단계 — 약관 사실이 필요한 B·D·F 그룹**만 KOFIA DIS·DART로 개별 확인하십시오. A그룹 108건을 전부 개별 확인하려 들지 마십시오. 판매사 결론값으로 충분한 종목이 대부분입니다.

## 8. 이번에는 반드시 지킬 것

1. **원본 스냅샷을 먼저 저장하고 그 다음에 판정하십시오.** `data/regulatory/sources/brokers/{증권사}/{yyyymmdd}.html` 형태로 저장한 뒤, 그 파일에서 파싱한 값만 원장에 씁니다
2. `evidence_quote`에는 **스냅샷에서 실제로 읽은 문자열**을 넣으십시오. 템플릿 문장 금지
3. `source_url`은 **종목이 실제로 나타난 페이지**여야 합니다. 대표 URL 하나를 전 행에 반복 금지
4. 판매사 단독 승격 금지. **2개사 이상 일치** 필수
5. `WHITELISTED_SHARED_EVIDENCE`에 새 파일을 추가하지 마십시오. 저장소 내부에서 생성한 파일은 증거가 될 수 없습니다
6. 확인되지 않은 종목은 **확인되지 않았다고 보고**하십시오. 목표 수치를 채우기 위한 승격 금지

## 9. 도달 가능한 지점에 대한 현실적 전망

- **A·E·F·G 그룹**은 위 경로로 대부분 해결됩니다
- **C그룹 중 CD·KOFR 특별자산 10건**(약 10조)은 판매사가 안전자산으로 표기하더라도 **조문 경로가 없다는 사실은 변하지 않습니다.** 이 경우 `pension_limit`은 판매사 표기를 따르되 `statutory_basis`는 공란으로 두고, 화면에 "가입한 퇴직연금사업자에서 최종 확인" 주석을 다십시오
- **B그룹 경계값 9건**은 약관 문언 확인이 유일한 해법입니다

**100%는 여전히 도달할 수 없습니다.** 도달 가능한 현실적 목표는 **결론값 확보 90%대 + 법령 근거 확보 80%대**이며, 두 지표를 분리해 관리하는 편이 정확합니다.
