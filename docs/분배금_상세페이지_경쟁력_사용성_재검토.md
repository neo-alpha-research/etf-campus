# 분배금 상세 페이지 기준: 경쟁력·사용성 재검토

작성일: 2026-08-16 (KST)  
대상: ETF Campus 상세 페이지의 **PR 차트 + 분배금 지급 이력** 기준

## 1. 결론

현재 채택한 **가격 수익률(PR) 단일 차트와 분배금 지급 이력의 분리**는 현 데이터 성숙도와 국내 사용자 이해도에 비추어 적절하다. 글로벌 대형 운용사 상세 페이지는 완결된 총수익률·분배율·세후 성과를 함께 제공하지만, 해당 수치는 재투자 가정과 기준일·세금·비용 조건이 명확할 때만 유용하다. ETF Campus는 전 종목·전 기간의 동일한 검증 근거를 아직 확보하지 않았으므로, 총수익률처럼 보이는 수치를 먼저 노출하는 것보다 현금분배 사실을 독립 카드로 제공하는 방식이 더 신뢰할 수 있다.[1]

다만 현재 구현은 **‘안전하다’는 장점에 비해 지급 이력의 맥락이 조금 부족하다.** 경쟁 서비스의 공통 구조를 반영해 `분배 주기`, `최종 갱신일`, `원천 상태 설명`을 보완하면 사용자가 “얼마를 받았는가”뿐 아니라 “언제, 어떤 규칙으로, 얼마나 최신 정보인가”를 빠르게 판단할 수 있다.[2] [3]

> 권장 방향은 **TR 차트 재도입이 아니라, 지급 이력 카드의 정보 완성도를 한 단계 높이는 것**이다.

## 2. 경쟁 서비스 대비 평가

| 평가 영역 | ETF Campus 현재 기준 | 글로벌·국내 관행 | 평가 | 권장 조치 |
|---|---|---|---|---|
| 성과 기준 | 전 종목 PR 단일 기준 | iShares는 Total Return·Market Price·벤치마크를 구분해 제시 | **적절** | PR 문구와 정보 아이콘을 유지하고, 불완전한 TR은 계속 보류 |
| 분배금과 성과의 분리 | 지급 이력을 별도 카드로 제공 | 운용사들은 성과와 분배 이력을 별도 섹션·표로 제공 | **적절** | 카드의 정보 밀도만 보완 |
| 핵심 일정 | 금액·분배락일·지급일 | Ex-Date·Record Date·Pay Date가 표준 핵심 열 | **적절** | 기준일은 확보된 경우에만 전체 이력의 보조 열로 추가 |
| 분배 주기 | 현재 미표시 | iShares는 Quarterly·Semi-annually 등 주기를 함께 표기 | **개선 필요** | 최근 12개월의 실제 이벤트로 산출 가능한 `월·분기·반기·연`만 표시 |
| 원천·검증 상태 | 운용사 공식 공지 기반 배지 | 운용사 자료와 공식 공시의 구분이 일반적 | **적절** | 배지 클릭 시 1문장 정의와 갱신일 제공 |
| 최신성 | 카드 안에서 즉시 확인이 어려움 | 기준일·공시일·데이터 시점이 성과·분배 정보에 병기됨 | **개선 필요** | `최종 갱신 YYYY.MM.DD`를 헤더 보조 문구로 표시 |
| 전체 이력 | 최근 3건과 펼침 표 | 과거 이력은 표 기반 조회가 일반적 | **적절** | 12건을 넘으면 전용 이력 페이지를 검토 |
| 분배율 | 미표시 | 일부 국내 서비스는 종가 대비 분배율을 제공 | **현재는 적절** | 산식·기준일·연환산 규칙이 확정되기 전에는 미노출 |

## 3. 사용자 관점 평가

### 3.1 유지해야 할 요소

**첫째, 기본 차트를 PR로 통일한 선택은 옳다.** 사용자는 ETF를 가로 비교할 때 먼저 가격 움직임과 동일 기간의 가격 수익률을 본다. 일부 ETF만 D2·D3를 보이면 동일 차트 안에서도 비교 기준이 달라지고, 사용자는 전환 상태나 커버리지 문구를 해석해야 한다. 현재 PR 단일 기준은 모든 ETF에 동일하게 적용되므로 탐색·비교·모바일 사용에서 인지 부담이 낮다.

**둘째, 분배금은 현금흐름 정보로 별도 제시하는 것이 좋다.** iShares와 SPDR의 공식 자료도 분배금 관련 날짜와 금액을 성과표와 구분된 지급 이력으로 관리한다.[2] [3] ETF Campus가 최근 주당 분배금·분배락일·지급일을 한 카드에 모은 것은 사용자가 투자 전 확인하고 싶은 최소 질문에 직접 답한다.

**셋째, 데이터가 없을 때 0으로 표기하지 않는 원칙을 유지해야 한다.** 분배금 카드가 없는 것은 정보 부족을 뜻하며, 0원이나 임의의 무분배 표시보다 정확하다. 단, 카드 자체가 보이지 않는 이유를 사용자가 오해하지 않도록 배당형으로 분류된 ETF에서는 한 줄의 안내가 필요하다.

### 3.2 우선 보완할 요소

| 우선순위 | 개선안 | 사용자 문제 | 화면 제안 | 데이터 조건 |
|---:|---|---|---|---|
| P0 | 분배 주기 표시 | 최근 1회 금액만으로 월분배·분기분배 여부를 판단하기 어려움 | `최근 12개월: 월 분배`를 카드 헤더 아래에 표시 | 최근 12개월 이벤트 간격이 일관될 때만 표시 |
| P0 | 최신 갱신일 표시 | 지급일이 지나도 데이터가 최신인지 판단하기 어려움 | `최종 갱신 2026.08.16`을 배지 아래의 보조 문구로 표시 | 요약 JSON의 `updatedAt` 사용 |
| P0 | 빈 상태 안내 | 배당형인데 카드가 없으면 무분배로 오해할 수 있음 | `분배금 정보 수집 중` + `공식 공지 확인 후 제공` | 배당형 분류이면서 요약 이벤트 없음 |
| P1 | 원천 상태 설명 | `운용사 공식 공지 기반`의 의미를 모를 수 있음 | 정보 아이콘 팝오버: `주당 금액·일정은 운용사 공지 기준이며, KIND 대조 여부는 이력 행에서 확인` | 원천·검증 상태 유지 |
| P1 | 기준일 보조 표기 | 지급 권리의 기준을 정확히 확인하려는 사용자가 있음 | 전체 이력에서만 `기준일` 열 제공 | `recordDate`가 있을 때만 |
| P2 | 전용 지급 이력 페이지 | 12건 이후의 장기 추이를 상세히 보고 싶음 | `/etf/[ticker]/distributions` 또는 상세 모달 | 이벤트 커버리지 확대 후 |

## 4. 권장 카드 구조

### 데스크톱

```text
분배금 지급 이력                                  [운용사 공식 공지 기반]
최근 12개월: 월 분배 · 최종 갱신 2026.08.16

최근 주당 분배금          103원
분배락일                  2026.07.30
지급일                    2026.08.04

최근 지급 내역                                      전체 보기
2026.07.30 분배락          103원       2026.08.04 지급
2026.06.27 분배락           98원       지급일 확인 중
```

### 모바일

카드는 기간 수익률 표 아래에 두되, 모바일 첫 화면에서 차트·수익률·카드가 지나치게 길어지지 않도록 최근 2건만 우선 표시하고 `전체 n건 보기`를 제공한다. 금액은 오른쪽에 고정하고, 날짜는 왼쪽에서 `분배락일 → 지급일` 순서로 배치한다. 분배 주기·최종 갱신일은 보조 문구 한 줄로 묶는다.

## 5. 명확히 피해야 할 요소

| 피해야 할 표시 | 이유 | 대안 |
|---|---|---|
| `분배금 포함` 토글만 있는 차트 | 실제로는 TR·추정·부분 커버리지의 차이를 숨김 | PR 차트를 유지하고 지급 이력으로 분리 |
| 최근 1회 분배금으로 연환산한 대표 수익률 | 지급 주기 변화·특별분배·원금반환을 과장할 수 있음 | 실제 이력과 확정된 분배 주기만 표시 |
| 카드 미노출을 무분배로 해석하게 하는 화면 | 원천 미확보와 실제 무분배를 혼동 | 배당형이면서 이벤트가 없으면 `정보 수집 중` 안내 |
| `지급 완료` 자동 표기 | 지급일 경과만으로 실제 지급 완료를 단정할 수 없음 | `지급일` 또는 `지급 예정일`처럼 사실 기반 표현 |
| PR과 TR을 한 표의 한 행에 혼합 | 수익률 정의가 달라 단순 비교가 불가능 | 현재 PR 단일 표 유지, TR은 별도 검증 단계 후 재검토 |

## 6. 구현 우선순위

1. **P0:** 분배 주기·최종 갱신일·빈 상태를 지급 이력 카드에 추가한다.
2. **P1:** 원천 상태 정보 아이콘과 전체 이력의 기준일 보조 열을 구현한다.
3. **P2:** 12건 초과 이력과 필터가 필요해지면 전용 이력 화면을 추가한다.
4. **보류:** 전 종목 TR·분배금 반영 수익률 차트는 데이터 검증 게이트 충족 이후 별도 과제로 재개한다.

## 7. 기준과 한계

- **수익률 기준:** 상세 차트와 기간 수익률 표는 시장 종가 기준 PR이다.
- **분배금 기준:** 카드의 금액은 주당 세전 현금분배금이며, 운용사 공식 공지를 우선 원천으로 사용한다.
- **시점:** 이 평가는 2026-08-16 KST에 확인한 페이지 구조와 원장 상태를 기준으로 한다.
- **한계:** 일부 운용사 페이지는 동적 렌더링으로 전체 표를 추출하지 못했으며, 해당 서비스의 공개 메뉴·공식 설명만 비교 근거로 사용했다.
