# 분배금 상세 페이지: 지급 이력 우선 결정안

작성일: 2026-08-16 (KST)  
상태: **채택 권고**

## 1. 결정

배당형 ETF에도 차트와 기간별 수익률 표는 당분간 **가격 수익률(PR)**만 제공한다. 분배금 반영 추정 수익률(D2)과 검증 TR(D3)은 화면 기능으로 노출하지 않고, 분배금 데이터는 **실제 지급·예정 내역을 확인하는 정보 영역**으로만 제공한다.

이 결정은 현재 분배금 원장이 수집·자동화 단계에는 진입했지만, 전 종목·전 기간에 대한 총수익률 계산에 필요한 분배락일·무분배 월·기업행동·가격 이력 검증을 아직 갖추지 못한 상태임을 반영한다. 불완전한 D2/D3를 차트에 넣는 것보다, 검증 가능한 사실만 보여 주는 편이 사용자 신뢰와 운영 효율에 유리하다.

> 차트는 **가격 변동을 보는 도구**, 분배금 영역은 **현금지급 이력을 확인하는 도구**로 역할을 분리한다.

## 2. 화면 적용 범위

| 영역 | 적용안 | 비고 |
|---|---|---|
| 가격 차트 | 기존 PR만 유지 | `분배금 미포함(PR)` 토글·문구·전환 로직 제거 |
| 대표 수익률 | 기존 PR만 유지 | 차트와 같은 기간·가격 기준 |
| 하단 기간 수익률 표 | 기존 PR 단일 행 유지 | 분배금 반영 수익률 행을 추가하지 않음 |
| 배당형 상세 카드 | `분배금 지급 이력` 블록 추가 | 원장에 확인된 이벤트가 있을 때만 노출 |
| 비배당형 ETF | 분배금 블록 미노출 | 화면 복잡도 방지 |

## 3. 분배금 지급 이력 카드

### 3.1 카드 위치

- **데스크톱:** 차트 오른쪽의 `투자 체크 지표` 패널 하단.
- **모바일:** 차트 바로 아래, 기간별 PR 수익률 표 바로 위.

### 3.2 카드 구성

```text
분배금 지급 이력                         [공식 공지 기반]
최근 주당 분배금       103원
분배락일               2026.07.30
지급일                 2026.08.04

최근 지급 내역                                      전체 보기 ›
2026.07.30          103원       2026.08.04 지급
2026.06.27           98원       지급일 확인 중
```

| 데이터 필드 | 원장 필드 | 표시 규칙 |
|---|---|---|
| 주당 분배금 | `distribution_per_share_krw` | `103원`처럼 원화 단위로 표시 |
| 분배락일 | `ex_date` | 가장 핵심 일정으로 우선 표시 |
| 기준일 | `record_date` | 있는 경우에만 `기준일`로 보조 표시 |
| 지급일 | `pay_date` | 값이 없으면 `지급일 확인 중` |
| 지급 상태 | `event_status` | 지급 전은 `예정`, 지급 확인 후는 `지급` |
| 검증 상태 | `verification_status` | 카드 우상단 배지와 각 행의 정보 팝오버에 표시 |

### 3.3 검증 상태 문구

| 원장 상태 | 사용자 노출 문구 | 허용 범위 |
|---|---|---|
| `verified` | `KIND 대조 완료` | 금액·분배락일이 모두 대조된 이벤트 |
| `partial` | `운용사 공식 공지 기반` | 공식 공지에서 금액·일정 중 일부가 확인된 이벤트 |
| `announced` | `지급 예정` | 공지됐지만 지급 전인 이벤트 |
| `conflict` | `확인 중` | 기본 카드에는 금액을 확정값처럼 표시하지 않음 |

지급일·기준일·분배락일이 비어 있으면 0, 임의 날짜, `미지급`으로 대체하지 않는다. 해당 필드는 `확인 중`으로 표시하거나 숨긴다.

## 4. 노출 조건

1. 배당형 분류이면서 정규 분배 이벤트가 1건 이상 있는 ETF만 카드를 보인다.
2. 최근 이벤트의 주당 분배금·분배락일 중 핵심 값이 없는 경우, 숫자 카드 대신 `분배금 정보 확인 중` 상태를 보인다.
3. 최근 내역은 최대 3건만 먼저 보이고, `전체 보기`에서 전체 이력 표를 펼친다.
4. 분배금 이력은 세전 주당 금액이며, 연 환산 분배율·예상 분배금·개인별 수령액을 기본 화면에 추정해 표시하지 않는다.
5. 원천과 갱신 시각은 정보 아이콘 또는 하단 고지에서 확인할 수 있게 한다.

## 5. 구현 우선순위

| 우선순위 | 작업 | 완료 기준 |
|---:|---|---|
| 1 | 이벤트 원장에서 티커별 최근 3건을 만드는 정적 요약 JSON 생성 | `amount`, `exDate`, `recordDate`, `payDate`, `status`, `updatedAt` 보유 |
| 2 | `DistributionHistoryCard` 컴포넌트 추가 | 데스크톱·모바일 위치와 상태별 빈 화면 구현 |
| 3 | ETF 상세 페이지에 요약 JSON 연결 | 원장 이벤트가 있는 배당형 ETF만 조건부 노출 |
| 4 | 최근 3건 및 전체 이력 화면 구현 | 날짜·금액·지급 상태·원천 상태 확인 가능 |
| 5 | 차트·기간 수익률의 D2/D3 토글과 추가 행 보류 | PR 단일 기준 회귀 테스트 통과 |

## 6. 향후 TR 기능 재개 기준

TR은 데이터가 축적된 뒤 별도 단계로 재검토한다. 재개 최소 조건은 배당형 ETF별로 다음을 모두 충족하는 것이다.

- 대상 기간의 운용사 공식 분배금·분배락일이 연속적으로 확보됨
- 무분배 월이 공식적으로 확인됨
- KIND 공시 대조 또는 동등한 1차 원천 대조가 완료됨
- 기업행동과 가격 이력 결손이 검증됨
- 해당 기간의 PR·TR 재현 계산 테스트가 통과함

그때도 첫 적용은 특정 ETF와 제한된 기간의 베타로 시작한다. 전체 배당형 ETF에 일괄 노출하지 않는다.

## 7. 기준과 한계

- **기준:** 화면의 수익률은 PR이며, 분배금 지급 이력은 주당 세전 현금분배금 사실 정보다.
- **원천:** 운용사 공식 공지와 KRX KIND 공시를 우선 사용한다.
- **한계:** 일부 이벤트는 지급일 또는 KIND 대조가 미완료일 수 있으며, 이 경우 상태 문구로 차이를 고지한다.
- **비적용:** 분배금 재투자 가정, 총수익률, 연 환산 분배율, 개인별 세후 수익은 현재 상세 화면에서 제공하지 않는다.

투자 참고용 정보이며, 개인 맞춤형 투자 조언이 아닙니다.
