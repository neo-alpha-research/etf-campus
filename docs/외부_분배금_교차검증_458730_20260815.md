## 3. 보조 대조와 한계

K-ETF 공개 차트와 Investing.com 공개 배당 이력에서도 36원과 45원 금액은 확인됐다. 다만 K-ETF는 브라우저 렌더링 차트에서 개별 행의 날짜를 독립적으로 추출하지 못했고, Investing.com은 브라우저 접근이 정책 제한되어 행별 날짜와 지급일을 재확인하지 못했다. 두 서비스의 결과는 `amount_present_not_row_dated`로만 기록했다.

더리치의 공개 API는 외부 서비스의 데이터 품질을 확인하는 2차 대조 원천이다. ETF Campus의 `verified` 상태를 바꾸거나 KIND 개별 공시를 대체하지 않으며, 운용사 공식 공지 및 KRX KIND가 1차 원천이라는 기존 원칙을 유지한다.

## 4. 운영 권고

외부 서비스 교차검증은 다음과 같이 운영한다. 운용사 공식 후보마다 외부 서비스에서 같은 분배락일·지급일·금액이 모두 확인되면 `external_exact_match`를 감사 메타데이터로 저장한다. 날짜 또는 지급일 없이 금액만 보이면 `amount_present_not_row_dated`로 저장하며 상태 승격에 사용하지 않는다. 서로 다른 값이 나오면 `external_conflict`로 기록하고, 운용사·KRX KIND 원문을 다시 확인한다.
