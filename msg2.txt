1. Production 계정·실제 개인정보·계좌 정보로 테스트하지 마십시오.

## 즉시 중단 조건

다음 중 하나라도 해당되면 이후 명령을 실행하지 마십시오.

- 현재 브랜치가 `community/phase-3-preview-rc`가 아님

- `wrangler.toml` 외에 추적된 변경 파일이 존재함

- 스테이징 파일이 `wrangler.toml` 하나가 아님

- `npm run lint`, `npm test`, `npm run build`, `git diff --check` 중 하나라도 실패함

- Preview 배포가 Push 후 생성된 커밋 SHA와 일치하지 않음

- 공개 API 응답에 Secret, 이메일, Auth UUID, SMTP 정보, 내부 토큰이 노출됨

- Preview Supabase 마이그레이션 목록이 로컬과 불일치함

- OTP·Turnstile·권한 스모크 테스트가 실패하거나 운영자가 수행할 수 없음

## 실행 절차

### 1. 작업 트리와 변경 범위 확인

다음을 실행하십시오.

```
Set-Location 'D:\ETFCampus-community-phase3-rc'
git branch --show-current
git rev-parse HEAD
git status --short
git diff --check
git diff -- wrangler.toml
```

현재 브랜치가 정확히 `community/phase-3-preview-rc`인지 확인하십시오. `supabase/.temp/`는 미추적 로컬 임시 디렉터리로 허용하되 커밋하지 마십시오. 다른 미추적 임시 파일이 있으면 원인을 보고하고 중단하십시오.

`wrangler.toml`의 `[env.preview.vars]`에 다음 세 줄이 있고, Production 영역에는 추가되지 않았는지 검증하십시오.

```
TURNSTILE_REQUIRED = "true"
TURNSTILE_SITE_KEY = "0x4AAAAAAAERgiu-KGHqnHRgP"
COMMUNITY_ENVIRONMENT = "preview"
```

### 2. 로컬 회귀 검증

변경이 위 Preview 공개 변수 세 줄뿐이면 아래를 순서대로 실행하십시오.

```
npm run lint
npm test
npm run build
git diff --check
```

실패 시 어떠한 수정도 하지 말고 중단하십시오. 성공 시에만 다음 단계로 진행하십시오.

### 3. Preview 브랜치 전용 커밋과 Push

다음을 실행하십시오.

```
git add -- wrangler.toml
git diff --cached --check
git diff --cached --name-only
git diff --cached -- wrangler.toml
```

staged 파일이 `wrangler.toml` 하나뿐이고 diff가 Preview 공개 변수 세 줄 추가뿐일 때만 다음을 실행하십시오.

```
git commit -m "fix(preview ): add Turnstile and environment vars to wrangler.toml"
git rev-parse HEAD
git push origin community/phase-3-preview-rc
```

커밋 후 HEAD를 `PREVIEW_DEPLOY_COMMIT`으로 기록하십시오. `main`에는 어떠한 변경도 Push하지 마십시오.

### 4. Cloudflare Preview 배포 확인

Git 연동으로 실행된 Cloudflare Pages 프로젝트 `etf-campus`의 `community/phase-3-preview-rc` **Preview 배포만** 확인하십시오. 필요할 때만 같은 Preview 배포를 재시도할 수 있습니다. Production 배포 행은 선택·재시도·수정하지 마십시오.

최신 Preview 배포의 Git 커밋 SHA가 `PREVIEW_DEPLOY_COMMIT`과 정확히 일치하는지 확인하십시오. 배포가 성공한 뒤 다음 검증을 수행하십시오.

```
curl.exe -sS -I -L 'https://community-phase-3-preview-rc.etf-campus.pages.dev/community'
curl.exe -sS -L -o NUL -w 'community final=%{url_effective} status=%{http_code}`n' 'https://community-phase-3-preview-rc.etf-campus.pages.dev/community'
curl.exe -sS -L -o NUL -w 'posts final=%{url_effective} status=%{http_code}`n' 'https://community-phase-3-preview-rc.etf-campus.pages.dev/api/community/posts'
curl.exe -sS -L -o NUL -w 'auth-config final=%{url_effective} status=%{http_code}`n' 'https://community-phase-3-preview-rc.etf-campus.pages.dev/api/community/auth/config'
```

성공 기준은 다음과 같습니다.

| 대상 | 성공 기준 |
| --- | --- |
| `/community` | 리디렉션 최종 URL이 Preview 도메인 내이고 최종 HTTP 200 |
| `/api/community/posts` | 최종 HTTP 200, 목록 또는 빈 목록 응답, 이메일·Auth UUID·Secret 미노출 |
| `/api/community/auth/config` | 최종 HTTP 200, 예상 공개 site key와 Turnstile required 설정만 공개, Secret·SMTP·내부 토큰 미노출 |
| Cloudflare 배포 | 브랜치와 배포 커밋 SHA가 `PREVIEW_DEPLOY_COMMIT`과 일치 |

### 5. Preview Supabase 마이그레이션 읽기 전용 대조

원격 DB를 변경하지 않는 방식으로 Preview Supabase에 다음 마이그레이션이 적용돼 있는지 대조하십시오.

```
20260815000001_community_phase2.sql
20260815000002_community_security_hardening.sql
20260815000003_community_withdrawal_state_machine.sql
```

불일치하면 `db push`, 마이그레이션 수정, 재적용을 하지 말고 즉시 중단하십시오.

### 6. 운영자와 공동으로 수행할 OTP·권한 스모크 테스트

OTP 이메일 수신, 테스트 이메일 주소 입력, 인증 코드 입력, 로그인은 운영자가 브라우저에서 직접 수행합니다. OTP 코드·이메일·개인정보를 요청하거나 기록하지 마십시오. 운영자 조작이 필요한 경우 해당 화면을 연 뒤, 어떤 비민감 단계에서 입력이 필요한지만 안내하고 기다리십시오.

운영자가 아래 결과를 직접 확인할 수 있도록 지원하십시오.

1. 비로그인 사용자가 커뮤니티 목록과 게시물 상세를 읽을 수 있음

1. 비로그인 사용자의 `/community/write` 접근 및 작성·댓글 API가 차단됨

1. 로그인 창에 Turnstile이 표시되고, 통과 전 OTP 요청이 차단됨

1. 테스트 전용 이메일로 OTP 발송·수신·로그인 성공

1. 공개 닉네임 설정 및 세션 유지

1. 제목에 `[PREVIEW-TEST]` 접두사를 붙인 테스트 게시물·댓글 작성

1. 작성자 본인만 자신의 게시물·댓글을 수정 또는 정책상 삭제할 수 있음

1. 두 번째 테스트 계정이 타인의 콘텐츠를 수정·삭제할 수 없음

1. 로그아웃 뒤 읽기만 가능하고 쓰기·댓글 API가 거부됨

1. 테스트 전용 계정으로 탈퇴 성공·실패·재시도 흐름 확인

1. 화면과 공개 API에서 이메일·Auth UUID·서비스 역할 키·SMTP 정보가 노출되지 않음

1. 테스트가 끝나면 `[PREVIEW-TEST]` 콘텐츠를 작성자 권한과 운영 정책에 따라 정리

운영자의 OTP 입력이 필요해 대기하게 된 경우에는 그 시점까지의 자동 검증 결과를 유지하고, OTP·권한 테스트는 **운영자 확인 대기**로 명확히 표시하십시오. 이 경우 최종 판정은 `Preview 반영 보류 — Production 미변경`입니다.
