> 상태: 캐릭터명·브랜드 스토리 내부 확정(2026-07-21) · 공개 사용 전 상표 전문 검토 및 Navigator 반영 필요

## 브랜드 정의

- 서비스명: **ETF 캠퍼스**
- 캐릭터명: **티커리**
- 영문명: **TICKERY**
- 이름의 의미: **Ticker + Library**
- 한국어 해석: **ETF 티커와 정보를 차곡차곡 모아 정리하는 도서관 친구**
- 모티프: 자료를 모아 분류하는 다람쥐 큐레이터
- 역할: 종목을 권유하는 전문가가 아니라 데이터의 기준일·분류·주의점을 함께 확인하는 캠퍼스 조교
- 성격: 영리하지만 잘난 척하지 않고, 꼼꼼하지만 친근하다.

`티커리(TICKERY)`는 내부 캐릭터명과 브랜드 스토리로 확정한다. 다만 공개 URL, SNS 계정, 굿즈, 앱 이름 및 상표 출원은 선행상표 전문 검토와 Navigator 공개 게이트를 통과한 뒤 진행한다.

## 기능형 포즈 세트

`final-v2/`는 볼·몸통·팔다리를 더 둥글고 토실하게 다듬은 새 표준 후보이며, 화면 적용 시 우선 사용한다. `final/`은 비교·복구용 v1으로 보존한다. 생성 원본은 각각 `source-v2/`, `source/`에 보관한다.

A안의 얼굴·체형·조끼·색감을 기준으로 통일한 투명 배경 PNG다. 실제 화면에는 용도에 맞는 포즈를 한 영역에 한 번만 사용하고, ETF 데이터 표 내부에는 반복 배치하지 않는다.

- 형태: 작은 크기에서도 알아볼 수 있는 큰 꼬리와 둥근 실루엣
- 표정: 호기심과 차분함을 기본으로 하며 과장된 탐욕·공포·흥분은 사용하지 않는다.

## 말투와 행동

티커리는 예측하거나 권유하지 않고 확인할 기준을 제시한다.

- “이 숫자의 기준일을 먼저 확인해 볼까요?”
- “수익률이 비어 있으면 임의로 채우지 않아요.”
- “같은 자산군끼리 펼쳐보면 차이가 더 잘 보여요.”
- “미래 수익률은 알 수 없지만, 확인할 기준은 함께 볼 수 있어요.”

금지: 매수·매도 신호, 목표가, 상승 확신, 수익 보장, 특정 ETF 추천, 투자 적합성 판정.

## 그래픽 금지 요소

- 상승 화살표, 로켓, 돈주머니, 동전, 통화 기호
- 매수·매도 버튼 또는 차트 신호를 연상시키는 소품
- 실제 ETF명이나 실제 수익률을 들고 있는 모습
- 캐릭터가 이용자의 투자 결정을 대신하는 장면
- 원본 비율·색상·표정을 임의로 변형한 파생 이미지

## 사이트 적용 우선순위

1. 투자 스타일 진단의 시작·결과 화면
2. 데이터 없음·기준일·소규모 유의 안내
3. 자산군 가이드와 브리핑의 섹션 앵커
